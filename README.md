# 🎓 HTML та JavaScript - Інтерактивні уроки

## ✨ Особливості

- 🌓 **Темна/світла тема** - перемикач теми зі збереженням вибору
- 📱 **Адаптивний дизайн** - mobile-first підхід, працює на всіх пристроях
- 🧭 **Зручна навігація** - бічна панель, що згортається на мобільних
- 📊 **Відстеження прогресу** - позначайте пройдені уроки
- 💻 **Інтерактивні приклади** - запускайте код прямо в браузері
- 🎨 **Сучасний UI** - чистий інтерфейс з плавними анімаціями

## 🛠 Технології

- **Docker Compose** - контейнеризація додатку
- **Nginx Alpine** - легкий та швидкий веб-сервер
- **HTML5** - семантична розмітка
- **CSS3** - сучасні стилі з змінними та анімаціями
- **Vanilla JavaScript** - без фреймворків (додаток сам є навчальним)

## 🚀 Швидкий старт

### Запуск через Docker (рекомендовано)

1. Переконайтеся, що у вас встановлено [Docker](https://www.docker.com/) та Docker Compose

2. Клонуйте репозиторій:
```bash
git clone https://github.com/plamagnum/html_lessons.git
cd html_lessons
```

3. Запустіть додаток:
```bash
docker-compose up --build
```

4. Відкрийте браузер та перейдіть на:
```
http://localhost:8080
```

5. Для зупинки натисніть `Ctrl+C` або виконайте:
```bash
docker-compose down
```

### Запуск без Docker

Просто відкрийте файл `src/index.html` у вашому браузері. Всі функції працюватимуть локально.

## 📚 Програма навчання

### HTML блок (Уроки 1-8)

1. **Семантичний HTML5** - header, nav, main, section, article, aside, footer. Важливість семантики
2. **Таблиці та списки** - складні таблиці (colspan, rowspan), вкладені списки, dl/dt/dd
3. **Форми (частина 1)** - типи input (text, email, number, date, range, color), label, fieldset, legend
4. **Форми (частина 2)** - валідація (required, pattern, min/max), select, textarea, datalist
5. **Мультимедіа** - audio, video, source, picture, figure/figcaption, iframe
6. **Meta-теги та SEO** - viewport, description, Open Graph теги, структуровані дані
7. **Посилання та навігація** - якорі, відносні/абсолютні шляхи, target, download, навігаційні патерни
8. **Доступність (a11y)** - ARIA-атрибути, role, aria-label, alt тексти, клавіатурна навігація

### CSS блок (Уроки 9-12)

9. **CSS Flexbox** - всі властивості flex-контейнера та flex-елементів з прикладами лейаутів
10. **CSS Grid** - grid-template, areas, auto-fit/auto-fill, практичні лейаути
11. **CSS анімації** - transition, transform, @keyframes, практичні приклади
12. **CSS змінні та адаптивний дизайн** - custom properties, media queries, mobile-first підхід

### JavaScript блок (Уроки 13-20)

13. **Основи JavaScript** - змінні (let/const), типи даних, оператори, рядки, шаблонні літерали
14. **Функції та масиви** - оголошення функцій, стрілкові функції, методи масивів (map, filter, reduce)
15. **DOM маніпуляції** - querySelector, createElement, addEventListener, classList
16. **Події та обробники** - click, input, submit, делегування подій, event object
17. **Робота з формами через JS** - отримання значень, валідація, FormData, динамічні форми
18. **LocalStorage та JSON** - збереження даних, серіалізація, CRUD операції
19. **Fetch API та асинхронність** - проміси, async/await, fetch, робота з публічними API
20. **Фінальний проєкт** - створення TODO-додатку, що об'єднує всі знання

## 🔧 Для розробників

### Зміна портів

Редагуйте `docker-compose.yml`:
```yaml
ports:
  - "3000:80"  # Змінити 8080 на бажаний порт
```

### Додавання нових уроків

1. Створіть новий HTML файл у `src/lessons/`
2. Використовуйте структуру існуючих уроків як шаблон
3. Додайте посилання у навігаційну панель `index.html` та всіх уроків
4. Оновіть змінну `totalLessons` у `src/js/app.js`

### Налаштування стилів

Всі стилі знаходяться в `src/css/style.css`. Кольорові змінні визначені в `:root` для світлої теми та `[data-theme="dark"]` для темної.

### Розробка без Docker

Для швидкої розробки просто відкривайте файли у браузері. Для тестування на локальному сервері:

```bash
cd src
python3 -m http.server 8080
```

або

```bash
cd src
npx serve
```
