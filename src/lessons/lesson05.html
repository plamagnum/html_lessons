Аудіо в HTML5

HTML5 надає нативний елемент <audio> для вбудовування аудіо-контенту без необхідності використання плагінів.

Базове використання

<audio controls>
    <source src="audio/song.mp3" type="audio/mpeg">
    <source src="audio/song.ogg" type="audio/ogg">
    Ваш браузер не підтримує аудіо елемент.
</audio>

Атрибути аудіо

<audio controls autoplay loop muted preload="auto">
    <source src="audio/background.mp3" type="audio/mpeg">
</audio>

Атрибути елемента audio

  • controls - показує елементи керування (play, pause, volume)
  • autoplay - автоматичне відтворення (може блокуватись браузером)
  • loop - зациклює відтворення
  • muted - початково без звуку
  • preload - попереднє завантаження: none, metadata, auto

Аудіо з JavaScript керуванням

<audio id="myAudio">
    <source src="audio/track.mp3" type="audio/mpeg">
</audio>

<button onclick="document.getElementById('myAudio').play()">Play</button>
<button onclick="document.getElementById('myAudio').pause()">Pause</button>
<button onclick="document.getElementById('myAudio').volume += 0.1">+</button>
<button onclick="document.getElementById('myAudio').volume -= 0.1">-</button>

Відео в HTML5

Елемент <video> дозволяє вбудовувати відео-контент безпосередньо у веб-сторінку.

Базове відео

<video controls width="640" height="360">
    <source src="video/movie.mp4" type="video/mp4">
    <source src="video/movie.webm" type="video/webm">
    <source src="video/movie.ogg" type="video/ogg">
    Ваш браузер не підтримує відео.
</video>

Відео з постером та субтитрами

<video controls width="800" poster="images/video-poster.jpg">
    <source src="video/tutorial.mp4" type="video/mp4">
    
    <!-- Субтитри -->
    <track kind="subtitles" src="subtitles/uk.vtt" 
           srclang="uk" label="Українська" default>
    <track kind="subtitles" src="subtitles/en.vtt" 
           srclang="en" label="English">
    
    <!-- Описи для доступності -->
    <track kind="descriptions" src="descriptions/uk.vtt" 
           srclang="uk" label="Аудіо-опис">
</video>

Атрибути елемента video

  • poster - зображення, яке показується до початку відтворення
  • width/height - розміри відео
  • controls - показує панель керування
  • autoplay - автозапуск
  • loop - зациклення
  • muted - без звуку
  • playsinline - відтворення inline на мобільних

Формати відео

Формат MIME-тип Підтримка
MP4 (H.264) video/mp4 Найкраща підтримка
WebM video/webm Chrome, Firefox, Opera
Ogg video/ogg Firefox, Chrome, Opera

Адаптивні зображення: Picture

Елемент <picture> дозволяє задавати різні зображення для різних розмірів екрану або роздільної здатності.

Art Direction (різні зображення)

<picture>
    <!-- Для широких екранів (мінімум 1200px) -->
    <source media="(min-width: 1200px)" 
            srcset="images/banner-large.jpg">
    
    <!-- Для середніх екранів (768px - 1199px) -->
    <source media="(min-width: 768px)" 
            srcset="images/banner-medium.jpg">
    
    <!-- Для малих екранів (за замовчуванням) -->
    <img src="images/banner-small.jpg" alt="Банер сайту">
</picture>

Підтримка різних форматів

<picture>
    <!-- Сучасний формат AVIF -->
    <source srcset="images/photo.avif" type="image/avif">
    
    <!-- Формат WebP -->
    <source srcset="images/photo.webp" type="image/webp">
    
    <!-- Запасний варіант - JPEG -->
    <img src="images/photo.jpg" alt="Фото">
</picture>

Різна роздільна здатність (1x, 2x, 3x)

<picture>
    <source srcset="images/logo.png 1x,
                    images/logo@2x.png 2x,
                    images/logo@3x.png 3x">
    <img src="images/logo.png" alt="Логотип">
</picture>

Figure та Figcaption

Елементи <figure> та <figcaption> використовуються для семантичного групування зображень з підписами. 

<figure>
    <img src="images/chart.png" alt="Графік продажів">
    <figcaption>
        Рис. 1: Динаміка продажів за 2024 рік
    </figcaption>
</figure>

<!-- З кількома зображеннями -->
<figure>
    <img src="images/product1.jpg" alt="Продукт 1">
    <img src="images/product2.jpg" alt="Продукт 2">
    <img src="images/product3.jpg" alt="Продукт 3">
    <figcaption>Наша колекція продуктів</figcaption>
</figure>

<!-- З кодом -->
<figure>
    <pre><code>
function greet(name) {
    console.log(`Hello, ${name}!`);
}
    </code></pre>
    <figcaption>Приклад 1: Проста функція привітання</figcaption>
</figure>

Iframe - вбудовування зовнішнього контенту

Елемент <iframe> дозволяє вбудовувати інші HTML-сторінки, карти, відео з YouTube тощо.

Базове використання

<iframe src="https://www.example.com" 
        width="800" height="600"
        title="Зовнішня сторінка">
</iframe>

YouTube відео

<iframe width="560" height="315"
        src="https://www.youtube.com/embed/VIDEO_ID"
        title="YouTube video player"
        frameborder="0"
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
        allowfullscreen>
</iframe>

Google Maps

<iframe 
    src="https://www.google.com/maps/embed?pb=!1m18!1m12..."
    width="600" 
    height="450"
    style="border:0;"
    allowfullscreen=""
    loading="lazy"
    referrerpolicy="no-referrer-when-downgrade">
</iframe>

Адаптивний iframe

<!-- HTML -->
<div class="video-container">
    <iframe src="https://www.youtube.com/embed/VIDEO_ID"
            allowfullscreen></iframe>
</div>

<!-- CSS -->
<style>
.video-container {
    position: relative;
    padding-bottom: 56.25%; /* 16:9 */
    height: 0;
    overflow: hidden;
}

.video-container iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
}
</style>

Важливі атрибути iframe

  • sandbox - обмежує можливості iframe (безпека)
  • loading="lazy" - відкладене завантаження
  • allow - дозволені функції (camera, microphone тощо)
  • referrerpolicy - політика referrer
  • allowfullscreen - дозволяє повноекранний режим

SVG - векторна графіка

SVG можна вбудовувати безпосередньо в HTML або як зовнішній файл.

Вбудований SVG

<svg width="200" height="200" xmlns="http://www.w3.org/2000/svg">
    <!-- Коло -->
    <circle cx="100" cy="100" r="80" 
            fill="#3498db" stroke="#2980b9" stroke-width="3" />
    
    <!-- Текст -->
    <text x="100" y="110" text-anchor="middle" 
          fill="white" font-size="24" font-weight="bold">
        SVG
    </text>
</svg>

SVG як зображення

<img src="images/logo.svg" alt="Логотип" width="200">

<!-- Або як фонове зображення в CSS -->
<div style="background-image: url('images/pattern.svg');">
    Контент з SVG фоном
</div>

Оптимізація мультимедіа

Lazy Loading (відкладене завантаження)

<!-- Зображення -->
<img src="images/large-photo.jpg" 
     alt="Велике фото" 
     loading="lazy">

<!-- Iframe -->
<iframe src="https://example.com" loading="lazy"></iframe>

<!-- Також працює з picture -->
<picture>
    <source srcset="images/photo.webp" type="image/webp">
    <img src="images/photo.jpg" alt="Фото" loading="lazy">
</picture>

Preload для критичних ресурсів

<head>
    <!-- Попереднє завантаження критичних зображень -->
    <link rel="preload" as="image" href="images/hero.jpg">
    
    <!-- Попереднє завантаження відео -->
    <link rel="preload" as="video" href="video/intro.mp4">
    
    <!-- Попереднє завантаження шрифтів -->
    <link rel="preload" as="font" 
          href="fonts/roboto.woff2" 
          type="font/woff2" crossorigin>
</head>

Повний приклад галереї

<section class="gallery">
    <h2>Фотогалерея</h2>
    
    <!-- Відео презентація -->
    <figure>
        <video controls width="100%" poster="images/video-poster.jpg">
            <source src="video/presentation.mp4" type="video/mp4">
            <source src="video/presentation.webm" type="video/webm">
            <track kind="subtitles" src="subtitles/uk.vtt" 
                   srclang="uk" label="Українська" default>
        </video>
        <figcaption>Відео презентація проєкту</figcaption>
    </figure>
    
    <!-- Адаптивні зображення -->
    <figure>
        <picture>
            <source media="(min-width: 1200px)" 
                    srcset="images/landscape-large.webp" 
                    type="image/webp">
            <source media="(min-width: 768px)" 
                    srcset="images/landscape-medium.webp" 
                    type="image/webp">
            <source srcset="images/landscape-small.webp" 
                    type="image/webp">
            <img src="images/landscape.jpg" 
                 alt="Гірський пейзаж" 
                 loading="lazy">
        </picture>
        <figcaption>Карпатські гори восени</figcaption>
    </figure>
    
    <!-- Аудіо файл -->
    <figure>
        <figcaption>Послухайте наш подкаст:</figcaption>
        <audio controls>
            <source src="audio/podcast-episode-1.mp3" type="audio/mpeg">
            <source src="audio/podcast-episode-1.ogg" type="audio/ogg">
        </audio>
    </figure>
    
    <!-- Вбудована карта -->
    <figure>
        <iframe src="https://www.google.com/maps/embed?pb=..."
                width="100%" height="400" 
                style="border:0;" 
                loading="lazy"></iframe>
        <figcaption>Наше місцезнаходження</figcaption>
    </figure>
</section>

Підсумок

HTML5 надає потужні інструменти для роботи з мультимедіа: нативні елементи <audio> та <video>, адаптивні зображення через <picture>, семантичне групування з <figure>, та вбудовування зовнішнього контенту через <iframe>. Використовуйте lazy loading для оптимізації завантаження та надавайте різні формати для максимальної сумісності.
