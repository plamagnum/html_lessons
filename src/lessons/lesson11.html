Урок 11: CSS анімації

Створення динамічних анімацій за допомогою CSS

Що таке CSS анімації?

CSS анімації дозволяють створювати динамічні ефекти без JavaScript. Існують два основні способи анімації елементів: transitions (переходи) та animations (ключові кадри).

Переваги CSS анімацій

  • Висока продуктивність - використовують апаратне прискорення GPU
  • Простота використання - не потребують JavaScript
  • Плавні та природні переходи
  • Підтримка в усіх сучасних браузерах

CSS Transitions (Переходи)

Transitions дозволяють плавно змінювати CSS властивості при зміні їх значень. Ідеально підходять для простих анімацій при hover, focus, або зміні класів.

Основні властивості transition

.button {
    background-color: #3498db;
    padding: 10px 20px;
    border: none;
    color: white;
    
    /* Властивість transition */
    transition-property: background-color;
    transition-duration: 0.3s;
    transition-timing-function: ease;
    transition-delay: 0s;
    
    /* Скорочений запис */
    transition: background-color 0.3s ease 0s;
}

.button:hover {
    background-color: #2980b9;
}

Приклад: Анімація кнопки

<style>
.animated-button {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    border: none;
    color: white;
    padding: 15px 30px;
    font-size: 16px;
    border-radius: 8px;
    cursor: pointer;
    transition: all 0.3s ease;
    transform: scale(1);
}

.animated-button:hover {
    transform: scale(1.05);
    box-shadow: 0 10px 25px rgba(102, 126, 234, 0.5);
}

.animated-button:active {
    transform: scale(0.95);
}
</style>

<button class="animated-button">Натисни мене</button>

Функції часу (timing functions)

/* Вбудовані функції */
transition-timing-function: ease;        /* повільний старт і кінець */
transition-timing-function: linear;      /* рівномірна швидкість */
transition-timing-function: ease-in;     /* повільний старт */
transition-timing-function: ease-out;    /* повільний кінець */
transition-timing-function: ease-in-out; /* повільний старт і кінець */

/* Власна крива Безьє */
transition-timing-function: cubic-bezier(0.68, -0.55, 0.265, 1.55);

CSS Transform (Трансформації)

Transform дозволяє змінювати форму, розмір та позицію елементів без впливу на макет сторінки. 

/* Переміщення */
transform: translate(50px, 100px);
transform: translateX(50px);
transform: translateY(100px);

/* Масштабування */
transform: scale(1.5);        /* збільшити в 1.5 рази */
transform: scaleX(2);         /* розтягнути по горизонталі */
transform: scaleY(0.5);       /* стиснути по вертикалі */

/* Обертання */
transform: rotate(45deg);     /* повернути на 45 градусів */
transform: rotateX(180deg);   /* 3D обертання по осі X */
transform: rotateY(180deg);   /* 3D обертання по осі Y */

/* Нахил */
transform: skew(10deg, 20deg);
transform: skewX(10deg);

/* Комбінування трансформацій */
transform: translate(50px, 50px) rotate(45deg) scale(1.2);

Приклад: Картка з 3D ефектом

CSS Animations з @keyframes

@keyframes дозволяє створювати складні анімації з множинними кроками. На відміну від transitions, animations можуть повторюватися і виконуватися автоматично.

Базовий синтаксис

/* Визначаємо анімацію */
@keyframes fadeIn {
    0% {
        opacity: 0;
        transform: translateY(20px);
    }
    100% {
        opacity: 1;
        transform: translateY(0);
    }
}

/* Застосовуємо анімацію */
.element {
    animation-name: fadeIn;
    animation-duration: 1s;
    animation-timing-function: ease-out;
    animation-delay: 0s;
    animation-iteration-count: 1;
    animation-direction: normal;
    animation-fill-mode: forwards;
    
    /* Скорочений запис */
    animation: fadeIn 1s ease-out 0s 1 normal forwards;
}

Приклад: Пульсуюча анімація

@keyframes pulse {
    0% {
        transform: scale(1);
        box-shadow: 0 0 0 0 rgba(52, 152, 219, 0.7);
    }
    50% {
        transform: scale(1.05);
        box-shadow: 0 0 0 10px rgba(52, 152, 219, 0);
    }
    100% {
        transform: scale(1);
        box-shadow: 0 0 0 0 rgba(52, 152, 219, 0);
    }
}

.notification-badge {
    background-color: #e74c3c;
    color: white;
    padding: 5px 10px;
    border-radius: 20px;
    animation: pulse 2s infinite;
}

Практичні приклади

Анімація появи меню

@keyframes slideDown {
    from {
        opacity: 0;
        transform: translateY(-20px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.dropdown-menu {
    display: none;
    animation: slideDown 0.3s ease-out;
}

.dropdown:hover .dropdown-menu {
    display: block;
}

Анімація тексту що з'являється

@keyframes fadeInUp {
    from {
        opacity: 0;
        transform: translateY(30px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.title {
    animation: fadeInUp 0.8s ease-out;
}

.subtitle {
    animation: fadeInUp 0.8s ease-out 0.2s backwards;
}

.description {
    animation: fadeInUp 0.8s ease-out 0.4s backwards;
}

Shake анімація (струшування)

@keyframes shake {
    0%, 100% { transform: translateX(0); }
    10%, 30%, 50%, 70%, 90% { transform: translateX(-10px); }
    20%, 40%, 60%, 80% { transform: translateX(10px); }
}

.error-input {
    animation: shake 0.5s;
    border-color: red;
}

Оптимізація анімацій

Найкращі практики

  • Використовуйте transform та opacity - вони апаратно прискорені
  • Уникайте анімації width, height, top, left - вони викликають reflow
  • Додайте will-change для складних анімацій: will-change: transform, opacity;
  • Обмежуйте кількість одночасних анімацій на сторінці
  • Використовуйте animation-play-state для призупинення анімацій
/* Правильно - швидка анімація */
.optimized {
    transform: translateX(100px);
    opacity: 0.5;
    transition: transform 0.3s, opacity 0.3s;
}

/* Неправильно - повільна анімація */
.not-optimized {
    left: 100px;  /* викликає reflow */
    margin-left: 50px;  /* викликає reflow */
    transition: left 0.3s, margin-left 0.3s;
}

Підсумок

CSS анімації - потужний інструмент для створення інтерактивних інтерфейсів. Використовуйте transitions для простих змін при взаємодії, @keyframes для складних послідовних анімацій, та transform для оптимальної продуктивності. Пам'ятайте про помірність - анімації мають покращувати, а не заважати користувацькому досвіду.
