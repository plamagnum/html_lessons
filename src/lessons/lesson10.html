Урок 10: CSS Grid

Потужна двовимірна система компонування

Що таке CSS Grid?

CSS Grid Layout - це двовимірна система компонування, яка дозволяє створювати складні макети одночасно в рядках і колонках. На відміну від Flexbox (одновимірного), Grid працює з обома вимірами одразу, що робить його ідеальним для створення повноцінних макетів сторінок.

Основні поняття Grid

  • Grid контейнер - батьківський елемент з display: grid
  • Grid елементи - безпосередні діти контейнера
  • Grid лінії - розділові лінії між комірками
  • Grid треки - рядки та колонки
  • Grid комірки - перетин рядка і колонки
  • Grid області - прямокутник з кількох комірок

Створення Grid

display: grid

.container {
    display: grid; /* або inline-grid */
}

/* HTML */
<div class="container">
    <div>1</div>
    <div>2</div>
    <div>3</div>
    <div>4</div>
</div>

Визначення колонок і рядків

grid-template-columns

Визначає ширину колонок.

.container {
    display: grid;
    
    /* Три колонки фіксованої ширини */
    grid-template-columns: 200px 300px 200px;
    
    /* Відсоткові значення */
    grid-template-columns: 25% 50% 25%;
    
    /* Одиниці fr (fractional) - гнучкі частки */
    grid-template-columns: 1fr 2fr 1fr;
    
    /* Комбінація різних одиниць */
    grid-template-columns: 200px 1fr 200px;
    
    /* Функція repeat() */
    grid-template-columns: repeat(3, 1fr);
    
    /* Мінімум і максимум */
    grid-template-columns: repeat(3, minmax(200px, 1fr));
}

/* Поширені патерни */

/* Дві колонки: sidebar + content */
.layout {
    grid-template-columns: 250px 1fr;
}

/* Три рівні колонки */
.three-columns {
    grid-template-columns: repeat(3, 1fr);
}

/* 12-колонкова сітка */
.grid-12 {
    grid-template-columns: repeat(12, 1fr);
}

grid-template-rows

Визначає висоту рядків.

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    
    /* Явні рядки */
    grid-template-rows: 100px 200px 100px;
    
    /* Використання repeat */
    grid-template-rows: repeat(3, 100px);
    
    /* Мінімум і максимум */
    grid-template-rows: repeat(3, minmax(100px, auto));
    
    /* Автоматична висота */
    grid-template-rows: auto auto auto;
}

Відступи між елементами

gap (row-gap, column-gap)

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    
    /* Відступ між всіма комірками */
    gap: 20px;
    
    /* Різні відступи для рядків і колонок */
    gap: 20px 10px; /* row-gap column-gap */
    
    /* Або окремо */
    row-gap: 20px;
    column-gap: 10px;
}

Розміщення елементів

grid-column та grid-row

Визначає, які лінії займає елемент.

.container {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    grid-template-rows: repeat(3, 100px);
    gap: 10px;
}

/* Елемент займає від лінії 1 до лінії 3 (2 колонки) */
.item-1 {
    grid-column: 1 / 3;
    /* або */
    grid-column-start: 1;
    grid-column-end: 3;
}

/* Займає 2 колонки, починаючи з другої */
.item-2 {
    grid-column: 2 / 4;
}

/* Займає весь рядок (4 колонки) */
.item-3 {
    grid-column: 1 / 5; /* або -1 */
    grid-column: 1 / -1; /* до останньої лінії */
}

/* Span синтаксис (займає X комірок) */
.item-4 {
    grid-column: span 2; /* Займає 2 колонки */
}

/* Рядки */
.item-5 {
    grid-row: 1 / 3; /* Займає 2 рядки */
}

/* Скорочення grid-area */
.item-6 {
    /* row-start / column-start / row-end / column-end */
    grid-area: 1 / 1 / 3 / 3;
}

Іменовані Grid Lines

.container {
    display: grid;
    grid-template-columns: 
        [sidebar-start] 250px 
        [sidebar-end content-start] 1fr 
        [content-end];
    grid-template-rows:
        [header-start] 80px 
        [header-end main-start] 1fr 
        [main-end footer-start] 60px 
        [footer-end];
}

/* Використання іменованих ліній */
.header {
    grid-column: sidebar-start / content-end;
    grid-row: header-start / header-end;
}

.sidebar {
    grid-column: sidebar-start / sidebar-end;
    grid-row: main-start / main-end;
}

.content {
    grid-column: content-start / content-end;
    grid-row: main-start / main-end;
}

Grid Template Areas

Візуальний спосіб визначення макету.

.container {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-rows: 80px 1fr 60px;
    grid-template-areas:
        "header header"
        "sidebar content"
        "footer footer";
    gap: 10px;
    height: 100vh;
}

.header {
    grid-area: header;
}

.sidebar {
    grid-area: sidebar;
}

.content {
    grid-area: content;
}

.footer {
    grid-area: footer;
}

/* HTML */
<div class="container">
    <header class="header">Header</header>
    <aside class="sidebar">Sidebar</aside>
    <main class="content">Content</main>
    <footer class="footer">Footer</footer>
</div>

Складніший приклад з Grid Areas

.page-layout {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header  header  header"
        "sidebar content aside"
        "footer  footer  footer";
    gap: 15px;
    min-height: 100vh;
    padding: 20px;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.aside { grid-area: aside; }
.footer { grid-area: footer; }

/* Адаптивність */
@media (max-width: 768px) {
    .page-layout {
        grid-template-columns: 1fr;
        grid-template-areas:
            "header"
            "content"
            "sidebar"
            "aside"
            "footer";
    }
}

Вирівнювання

justify-items та align-items

Вирівнювання всіх елементів всередині їх комірок.

.container {
    display: grid;
    grid-template-columns: repeat(3, 200px);
    grid-template-rows: repeat(3, 100px);
    
    /* Горизонтальне вирівнювання */
    justify-items: start;   /* за замовчуванням: stretch */
    justify-items: end;
    justify-items: center;
    justify-items: stretch;
    
    /* Вертикальне вирівнювання */
    align-items: start;     /* за замовчуванням: stretch */
    align-items: end;
    align-items: center;
    align-items: stretch;
    
    /* Скорочення */
    place-items: center;    /* align-items justify-items */
    place-items: center start;
}

justify-self та align-self

Вирівнювання окремого елемента.

.item {
    justify-self: center; /* Горизонтально */
    align-self: center;   /* Вертикально */
    
    /* Скорочення */
    place-self: center;   /* align-self justify-self */
}

justify-content та align-content

Вирівнювання всієї сітки всередині контейнера.

.container {
    display: grid;
    grid-template-columns: repeat(3, 200px);
    width: 800px; /* Більше, ніж потрібно */
    height: 500px;
    
    /* Горизонтальне вирівнювання сітки */
    justify-content: start;
    justify-content: end;
    justify-content: center;
    justify-content: space-between;
    justify-content: space-around;
    justify-content: space-evenly;
    
    /* Вертикальне вирівнювання сітки */
    align-content: start;
    align-content: end;
    align-content: center;
    align-content: space-between;
    align-content: space-around;
    align-content: space-evenly;
    
    /* Скорочення */
    place-content: center; /* align-content justify-content */
}

auto-fit та auto-fill

Автоматичне створення колонок залежно від доступного простору.

auto-fill

Створює максимальну кількість колонок, навіть якщо вони порожні.

.container {
    display: grid;
    /* Створює стільки колонок по 200px, скільки поміститься */
    grid-template-columns: repeat(auto-fill, 200px);
    gap: 20px;
}

/* З minmax для адаптивності */
.responsive-grid {
    display: grid;
    /* Мінімум 250px, але може рости */
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    gap: 20px;
}

auto-fit

Розширює колонки для заповнення доступного простору.

.container {
    display: grid;
    /* Колонки автоматично розширюються */
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 20px;
}

/* Різниця між auto-fill і auto-fit:
   - auto-fill: додає порожні треки
   - auto-fit: розширює існуючі треки
*/

Адаптивна сітка без media queries

/* Магія адаптивності! */
.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 20px;
}

/* Карки автоматично підлаштовуються:
   - Широкий екран: 4+ карток в рядку
   - Середній екран: 2-3 картки
   - Вузький екран: 1 картка
   Все автоматично!
*/

Неявна сітка (Implicit Grid)

.container {
    display: grid;
    /* Явні колонки */
    grid-template-columns: repeat(3, 1fr);
    
    /* Явні рядки (перші 2) */
    grid-template-rows: 100px 100px;
    
    /* Висота автоматичних рядків (3-го, 4-го...) */
    grid-auto-rows: 150px;
    
    /* Або мінімум/максимум */
    grid-auto-rows: minmax(100px, auto);
    
    /* Напрямок автоматичних елементів */
    grid-auto-flow: row;     /* за замовчуванням */
    grid-auto-flow: column;  /* горизонтально */
    grid-auto-flow: dense;   /* щільна упаковка */
}

Grid vs Flexbox

Коли використовувати Grid?

  • Двовимірні макети (рядки + колонки)
  • Повні макети сторінок
  • Складні сітки з різними розмірами
  • Потреба в точному контролі над розміщенням

Коли використовувати Flexbox?

  • Одновимірні макети (тільки рядок або колонка)
  • Компоненти інтерфейсу
  • Навігаційні меню
  • Вирівнювання контенту

Комбінуйте обидва!

Часто найкращий підхід - використовувати Grid для загального макету і Flexbox для окремих компонентів.

grid-template-columns Контейнер Визначає колонки
grid-template-rows Контейнер Визначає рядки
grid-template-areas Контейнер Іменовані області
gap Контейнер Відступи між комірками
justify-items Контейнер Горизонтальне вирівнювання всіх
align-items Контейнер Вертикальне вирівнювання всіх
justify-content Контейнер Вирівнювання сітки горизонтально
align-content Контейнер Вирівнювання сітки вертикально
grid-auto-rows Контейнер Розмір неявних рядків
grid-auto-columns Контейнер Розмір неявних колонок
grid-auto-flow Контейнер Напрямок автоматичного розміщення
grid-column Елемент Розміщення по колонках
grid-row Елемент Розміщення по рядках
grid-area Елемент Іменована область або позиція
justify-self Елемент Горизонтальне вирівнювання
align-self Елемент Вертикальне вирівнювання

Корисні Grid функції

/* repeat() */
grid-template-columns: repeat(4, 1fr);
grid-template-columns: repeat(auto-fit, 200px);

/* minmax() */
grid-template-columns: repeat(3, minmax(200px, 1fr));

/* fit-content() */
grid-template-columns: fit-content(300px) 1fr;

/* min() та max() */
grid-template-columns: min(300px, 100%) 1fr;

/* clamp() */
grid-template-columns: repeat(auto-fit, minmax(clamp(250px, 30%, 350px), 1fr));

Підсумок

CSS Grid - найпотужніший інструмент для створення двовимірних макетів. Використовуйте grid-template-columns/rows для визначення структури, grid-template-areas для візуального оголошення макету, auto-fit/auto-fill з minmax() для адаптивних сіток без media queries. Grid ідеальний для повних макетів сторінок, а Flexbox - для компонентів. Комбінуйте обидві технології для максимальної потужності!
