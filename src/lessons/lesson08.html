Урок 8: Доступність (a11y)

ARIA атрибути, role, aria-label та доступна навігація

Що таке доступність?

Веб-доступність (a11y - accessibility) означає створення веб-сайтів, які можуть використовувати всі люди, включно з людьми з обмеженими можливостями. Це не лише етична необхідність, але й юридична вимога в багатьох країнах.

Хто користується допоміжними технологіями?

  • Люди з порушеннями зору (скрін-рідери)
  • Люди з обмеженою мобільністю (клавіатурна навігація)
  • Люди з порушеннями слуху (субтитри, транскрипти)
  • Люди з когнітивними особливостями
  • Тимчасові обмеження (зламана рука, яскраве сонце)

Семантичний HTML - основа доступності

Використання правильних HTML елементів автоматично надає багато доступності. 

<!-- ПОГАНО:Div як кнопка -->
<div onclick="submitForm()">Надіслати</div>

<!-- ДОБРЕ: Справжня кнопка -->
<button type="submit">Надіслати</button>

<!-- ПОГАНО: Span як посилання -->
<span onclick="location.href='/page'">Перейти</span>

<!-- ДОБРЕ: Справжнє посилання -->
<a href="/page">Перейти</a>

<!-- ПОГАНО: Div для навігації -->
<div class="navigation">
    <a href="/">Головна</a>
</div>

<!-- ДОБРЕ: Семантична навігація -->
<nav aria-label="Головна навігація">
    <a href="/">Головна</a>
</nav>

Атрибут alt для зображень

Кожне змістовне зображення повинно мати альтернативний текст. 

<!-- Змістовне зображення -->
<img src="chart.png" 
     alt="Графік продажів за 2024 рік показує зростання на 25%">

<!-- Декоративне зображення (порожній alt) -->
<img src="decorative-line.png" alt="">

<!-- Логотип з текстом -->
<img src="logo.png" alt="Назва компанії">

<!-- Функціональне зображення (іконка в посиланні) -->
<a href="/search">
    <img src="search-icon.svg" alt="Пошук">
</a>

<!-- Складне зображення -->
<figure>
    <img src="complex-diagram.png" 
         alt="Діаграма процесу розробки"
         aria-describedby="diagram-description">
    <figcaption id="diagram-description">
        Детальний опис: Процес складається з 5 етапів...
    </figcaption>
</figure>

Правила написання alt-тексту

  • Описуйте зміст та функцію, не зовнішній вигляд
  • Будьте лаконічні (до 125 символів)
  • Не починайте з "Зображення..." або "Картинка..."
  • Декоративні зображення мають порожній alt=""
  • Для складних зображень використовуйте довгі описи

ARIA (Accessible Rich Internet Applications)

ARIA додає додаткову семантику до HTML елементів для покращення доступності динамічного контенту.

ARIA Roles

<!-- Основні landmark roles -->
<div role="banner">Шапка сайту</div>
<div role="navigation">Навігація</div>
<div role="main">Головний контент</div>
<div role="complementary">Додатковий контент</div>
<div role="contentinfo">Футер</div>

<!-- Widget roles -->
<div role="button">Кнопка</div>
<div role="checkbox" aria-checked="true">Чекбокс</div>
<div role="tab">Вкладка</div>
<div role="tabpanel">Панель вкладки</div>
<div role="dialog">Діалог</div>
<div role="alert">Сповіщення</div>

<!-- Document structure roles -->
<div role="article">Стаття</div>
<div role="list">
    <div role="listitem">Елемент списку</div>
</div>

Важливо!

Краще використовувати нативні HTML елементи, ніж div з ARIA role. Наприклад, <button> краще, ніж <div role="button">.

ARIA Labels та Descriptions

aria-label

Надає мітку елементу, яка не відображається візуально.

<!-- Кнопка з іконкою без тексту -->
<button aria-label="Закрити діалог">
    <svg>...</svg>
</button>

<!-- Навігація -->
<nav aria-label="Головна навігація">
    <a href="/">Головна</a>
</nav>

<!-- Пошук -->
<form role="search" aria-label="Пошук по сайту">
    <input type="search" placeholder="Пошук...">
</form>

<!-- Соціальні мережі -->
<a href="https://facebook.com/..." aria-label="Facebook">
    <svg>...</svg>
</a>

aria-labelledby

Вказує на інший елемент, який є міткою.

<h2 id="section-title">Контактна інформація</h2>
<section aria-labelledby="section-title">
    <p>Контент секції...</p>
</section>

<!-- Діалог -->
<div role="dialog" aria-labelledby="dialog-title">
    <h2 id="dialog-title">Підтвердження видалення</h2>
    <p>Ви впевнені?</p>
</div>

aria-describedby

Посилається на елемент з додатковим описом.

<label for="password">Пароль</label>
<input type="password" 
       id="password" 
       aria-describedby="password-help">
<small id="password-help">
    Мінімум 8 символів, включно з цифрою та спецсимволом
</small>

<!-- Кнопка з описом -->
<button aria-describedby="delete-description">
    Видалити
</button>
<span id="delete-description" hidden>
    Видалення є незворотнім
</span>

ARIA States та Properties

aria-hidden

Приховує елемент від скрін-рідерів.

<!-- Декоративна іконка -->
<span aria-hidden="true">★</span>
<span>Рейтинг 5/5</span>

<!-- Font icon -->
<i class="fa fa-home" aria-hidden="true"></i>
<span class="sr-only">Головна</span>

aria-expanded

Показує, чи розгорнутий елемент.

<button aria-expanded="false" 
        aria-controls="menu">
    Меню
</button>
<ul id="menu" hidden>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
</ul>

aria-current

Вказує поточний елемент у наборі.

<nav>
    <a href="/" aria-current="page">Головна</a>
    <a href="/about">Про нас</a>
    <a href="/contact">Контакти</a>
</nav>

<!-- Кроки -->
<ol>
    <li aria-current="step">Крок 1: Завершено</li>
    <li>Крок 2: В процесі</li>
    <li>Крок 3: Не почато</li>
</ol>

aria-live

Оголошує динамічні зміни користувачу.

<!-- Важливі оновлення -->
<div role="alert" aria-live="assertive">
    Помилка: Невірний пароль
</div>

<!-- Неважливі оновлення -->
<div aria-live="polite">
    Завантажується...
</div>

<!-- Статус -->
<div role="status" aria-live="polite">
    Файл успішно завантажено
</div>

Інші корисні атрибути

<!-- aria-disabled -->
<button aria-disabled="true">Недоступна кнопка</button>

<!-- aria-checked -->
<div role="checkbox" aria-checked="true">Згоден</div>

<!-- aria-selected -->
<div role="tab" aria-selected="true">Активна вкладка</div>

<!-- aria-required -->
<input type="text" aria-required="true">

<!-- aria-invalid -->
<input type="email" aria-invalid="true" aria-describedby="email-error">
<span id="email-error">Невірний формат email</span>

Клавіатурна навігація

Всі інтерактивні елементи повинні бути доступні з клавіатури.

tabindex

<!-- tabindex="0" - природний порядок табуляції -->
<div tabindex="0" role="button">Доступно з клавіатури</div>

<!-- tabindex="-1" - програмно фокусований, але не в tab order -->
<div tabindex="-1" id="skip-target">Контент</div>

<!-- ПОГАНО: позитивні значення (не використовуйте) -->
<input tabindex="1"> <!-- Не робіть так -->

<!-- Skip link -->
<a href="#main-content" class="skip-link">
    Перейти до контенту
</a>
<main id="main-content" tabindex="-1">
    Основний контент
</main>

Кастомні елементи з клавіатурою

<!-- Кнопка з клавіатурою -->
<div role="button" 
     tabindex="0"
     onkeydown="if(event.key === 'Enter' || event.key === ' ') handleClick()"
     onclick="handleClick()">
    Натисніть мене
</div>

<script>
function handleClick() {
    console.log('Clicked!');
}
</script>

Основні клавіші навігації

  • Tab - переміщення вперед
  • Shift + Tab - переміщення назад
  • Enter - активація посилань та кнопок
  • Space - активація кнопок, чекбоксів
  • Arrow keys - навігація в меню, списках
  • Esc - закриття діалогів

Візуально прихований текст

Текст для скрін-рідерів, який не відображається візуально.

<!-- CSS клас для скрін-рідерів -->
<style>
.sr-only {
    position: absolute;
    width: 1px;
    height: 1px;
    padding: 0;
    margin: -1px;
    overflow: hidden;
    clip: rect(0, 0, 0, 0);
    white-space: nowrap;
    border: 0;
}
</style>

<!-- Використання -->
<button>
    <svg aria-hidden="true">...</svg>
    <span class="sr-only">Закрити</span>
</button>

<a href="/">
    <img src="logo.png" alt="">
    <span class="sr-only">Головна сторінка</span>
</a>

Доступні форми

<form>
    <!-- Завжди використовуйте label -->
    <label for="username">Ім'я користувача:</label>
    <input type="text" 
           id="username" 
           name="username"
           required
           aria-required="true"
           aria-describedby="username-help">
    <small id="username-help">Мінімум 3 символи</small>
    
    <!-- Група радіо-кнопок -->
    <fieldset>
        <legend>Оберіть спосіб доставки</legend>
        <label>
            <input type="radio" name="delivery" value="courier">
            Кур'єр
        </label>
        <label>
            <input type="radio" name="delivery" value="pickup">
            Самовивіз
        </label>
    </fieldset>
    
    <!-- Помилка валідації -->
    <label for="email">Email:</label>
    <input type="email" 
           id="email"
           aria-invalid="true"
           aria-describedby="email-error">
    <span id="email-error" role="alert">
        Невірний формат email
    </span>
</form>

Повний доступний приклад

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Доступний сайт</title>
</head>
<body>
    <!-- Skip link -->
    <a href="#main-content" class="skip-link">
        Перейти до основного контенту
    </a>
    
    <header role="banner">
        <h1>Назва сайту</h1>
        
        <nav aria-label="Головна навігація">
            <ul>
                <li><a href="/" aria-current="page">Головна</a></li>
                <li><a href="/about">Про нас</a></li>
                <li><a href="/contact">Контакти</a></li>
            </ul>
        </nav>
    </header>
    
    <main id="main-content" tabindex="-1">
        <article>
            <h2>Заголовок статті</h2>
            
            <img src="photo.jpg" 
                 alt="Опис важливого зображення">
            
            <p>Контент статті...</p>
            
            <!-- Інтерактивний елемент -->
            <button aria-expanded="false" 
                    aria-controls="details">
                Показати деталі
            </button>
            
            <div id="details" hidden>
                <p>Додаткова інформація...</p>
            </div>
        </article>
        
        <!-- Live region для оновлень -->
        <div role="status" aria-live="polite" aria-atomic="true">
            <!-- Динамічний контент -->
        </div>
    </main>
    
    <aside role="complementary" aria-label="Пов'язаний контент">
        <h2>Схожі статті</h2>
        <nav aria-label="Схожі статті">
            <ul>
                <li><a href="/article1">Стаття 1</a></li>
                <li><a href="/article2">Стаття 2</a></li>
            </ul>
        </nav>
    </aside>
    
    <footer role="contentinfo">
        <p>© 2024 Назва компанії</p>
    </footer>
</body>
</html>

Інструменти тестування доступності

Рекомендовані інструменти

  • WAVE - розширення браузера для аналізу доступності
  • axe DevTools - інструменти розробника
  • Lighthouse - вбудовано в Chrome DevTools
  • NVDA/JAWS - скрін-рідери для тестування
  • Keyboard navigation - тестуйте лише клавіатурою
  • Color contrast checker - перевірка контрастності

Підсумок

Доступність - не додаткова функція, а фундаментальна частина веб-розробки. Використовуйте семантичний HTML, додавайте ARIA атрибути де потрібно, забезпечте клавіатурну навігацію, надавайте альтернативний текст для зображень, тестуйте з допоміжними технологіями. Доступний сайт краще для всіх користувачів і має кращі показники SEO.
