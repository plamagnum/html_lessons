Урок 4: Форми (частина 2)

Валідація форм, select, textarea та datalist

Валідація форм у HTML5

HTML5 надає вбудовані механізми валідації, які працюють без JavaScript. Браузер автоматично перевіряє дані перед відправкою форми.

Атрибут required

Робить поле обов'язковим для заповнення.

<label for="username">Ім'я користувача:</label>
<input type="text" id="username" name="username" required>

<label for="email">Email:</label>
<input type="email" id="email" name="email" required>

<label>
    <input type="checkbox" name="terms" required>
    Я приймаю умови використання
</label>

Атрибути min, max та step

Визначають діапазон та крок для числових полів та дат.

<!-- Вік від 18 до 100 -->
<label for="age">Вік:</label>
<input type="number" id="age" name="age" 
       min="18" max="100" required>

<!-- Ціна з кроком 0.01 -->
<label for="price">Ціна:</label>
<input type="number" id="price" name="price" 
       min="0" max="10000" step="0.01">

<!-- Дата не раніше 2020 року -->
<label for="start-date">Дата початку:</label>
<input type="date" id="start-date" name="start-date" 
       min="2020-01-01" required>

Атрибути minlength та maxlength

Визначають мінімальну та максимальну довжину тексту.

<!-- Пароль від 8 до 20 символів -->
<label for="password">Пароль:</label>
<input type="password" id="password" name="password" 
       minlength="8" maxlength="20" required>

<!-- Коментар до 200 символів -->
<label for="comment">Коментар:</label>
<textarea id="comment" name="comment" 
          maxlength="200"></textarea>

Валідація за допомогою pattern (регулярні вирази)

Атрибут pattern дозволяє задати власний шаблон валідації за допомогою регулярних виразів. 

<!-- Український номер телефону -->
<label for="phone">Телефон:</label>
<input type="tel" id="phone" name="phone" 
       pattern="^\+380\d{9}$"
       placeholder="+380XXXXXXXXX"
       title="Формат: +380XXXXXXXXX">

<!-- Тільки латинські літери -->
<label for="username">Username:</label>
<input type="text" id="username" name="username" 
       pattern="[A-Za-z]{3,16}"
       title="3-16 латинських літер">

<!-- Поштовий індекс -->
<label for="zipcode">Індекс:</label>
<input type="text" id="zipcode" name="zipcode" 
       pattern="\d{5}"
       placeholder="01001"
       title="5 цифр">

<!-- Hex колір -->
<label for="hexcolor">Колір (HEX):</label>
<input type="text" id="hexcolor" name="hexcolor" 
       pattern="^#[0-9A-Fa-f]{6}$"
       placeholder="#FF5733"
       title="Формат: #RRGGBB">

Корисні регулярні вирази

  • [A-Za-z]+ - тільки латинські літери
  • \d+ - тільки цифри
  • [А-Яа-яІіЇїЄєҐґ]+ - українські літери
  • ^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}$ - email

Textarea - багаторядкове текстове поле

Елемент <textarea> використовується для введення багаторядкового тексту. 

<label for="message">Повідомлення:</label>
<textarea id="message" name="message" 
          rows="5" cols="50"
          placeholder="Введіть ваше повідомлення тут..."
          maxlength="500"></textarea>

<!-- З початковим текстом -->
<label for="bio">Біографія:</label>
<textarea id="bio" name="bio" rows="10">Розкажіть про себе...</textarea>

Атрибути textarea

  • rows - кількість видимих рядків
  • cols - ширина в символах
  • wrap - як переносити текст (soft/hard)
  • resize (CSS) - дозволяє зміну розміру

Select - випадаючий список

Елемент <select> створює випадаючий список опцій.

Простий select

<label for="country">Країна:</label>
<select id="country" name="country" required>
    <option value="">Оберіть країну</option>
    <option value="ua">Україна</option>
    <option value="pl">Польща</option>
    <option value="de">Німеччина</option>
    <option value="us" selected>США</option>
</select>

Групування опцій за допомогою optgroup

<label for="car">Автомобіль:</label>
<select id="car" name="car">
    <optgroup label="Японські">
        <option value="toyota">Toyota</option>
        <option value="honda">Honda</option>
        <option value="nissan">Nissan</option>
    </optgroup>
    <optgroup label="Німецькі">
        <option value="bmw">BMW</option>
        <option value="mercedes">Mercedes-Benz</option>
        <option value="audi">Audi</option>
    </optgroup>
    <optgroup label="Американські">
        <option value="ford">Ford</option>
        <option value="chevrolet">Chevrolet</option>
    </optgroup>
</select>

Множинний вибір

<label for="skills">Навички (виберіть кілька):</label>
<select id="skills" name="skills" multiple size="5">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="js">JavaScript</option>
    <option value="react">React</option>
    <option value="node">Node.js</option>
    <option value="python">Python</option>
</select>
<small>Утримуйте Ctrl (Cmd на Mac) для вибору кількох</small>

Datalist - автодоповнення

Елемент <datalist> надає список варіантів для автодоповнення, але дозволяє вводити власні значення. 

<label for="browser">Ваш браузер:</label>
<input type="text" id="browser" name="browser" 
       list="browsers" placeholder="Почніть вводити...">

<datalist id="browsers">
    <option value="Google Chrome">
    <option value="Mozilla Firefox">
    <option value="Safari">
    <option value="Microsoft Edge">
    <option value="Opera">
</datalist>

Datalist з описами

<label for="city">Місто:</label>
<input type="text" id="city" name="city" list="cities">

<datalist id="cities">
    <option value="Київ">Столиця України</option>
    <option value="Львів">Культурна столиця</option>
    <option value="Одеса">Перлина біля моря</option>
    <option value="Харків">Східна столиця</option>
    <option value="Дніпро">Серце України</option>
</datalist>

Завантаження файлів

<!-- Один файл -->
<label for="avatar">Аватар:</label>
<input type="file" id="avatar" name="avatar" 
       accept="image/png, image/jpeg">

<!-- Кілька файлів -->
<label for="documents">Документи:</label>
<input type="file" id="documents" name="documents" 
       multiple accept=".pdf,.doc,.docx">

<!-- Лише зображення -->
<label for="photos">Фото:</label>
<input type="file" id="photos" name="photos" 
       multiple accept="image/*">

Типи MIME для accept

  • image/* - всі зображення
  • video/* - всі відео
  • audio/* - всі аудіо
  • .pdf - PDF файли
  • .doc,.docx - Word документи

CSS псевдокласи для валідації

Браузери надають псевдокласи для стилізації валідних та невалідних полів.

/* Валідне поле */
input:valid {
    border-color: green;
}

/* Невалідне поле */
input:invalid {
    border-color: red;
}

/* Поле з фокусом */
input:focus {
    outline: 2px solid blue;
}

/* Обов'язкове поле */
input:required {
    border-left: 3px solid orange;
}

/* Необов'язкове поле */
input:optional {
    border-left: 3px solid gray;
}

Підсумок

HTML5 валідація надає потужні інструменти для перевірки даних на стороні клієнта. Використовуйте required, pattern, min/max для валідації полів. Елементи <select>, <textarea> та <datalist> розширюють можливості збору інформації від користувачів. Завжди додавайте також серверну валідацію для безпеки.
