Урок 9: CSS Flexbox

Гнучка одновимірна система компонування

Що таке Flexbox?

Flexbox (Flexible Box Layout) - це одновимірна система компонування, яка дозволяє ефективно розподіляти простір між елементами контейнера і керувати їх вирівнюванням. "Одновимірна" означає, що flexbox працює або з рядками, або з колонками за раз.

Основні поняття Flexbox

  • Flex контейнер - батьківський елемент з display: flex
  • Flex елементи - безпосередні діти flex контейнера
  • Головна вісь - основний напрямок (row або column)
  • Поперечна вісь - перпендикулярна до головної

Властивості Flex контейнера

display: flex

Створює flex контейнер.

.container {
    display: flex; /* або inline-flex */
}

/* HTML */
<div class="container">
    <div>Елемент 1</div>
    <div>Елемент 2</div>
    <div>Елемент 3</div>
</div>

flex-direction

Визначає напрямок головної осі.

.container {
    display: flex;
    
    /* Горизонтально зліва направо (за замовчуванням) */
    flex-direction: row;
    
    /* Горизонтально справа наліво */
    flex-direction: row-reverse;
    
    /* Вертикально зверху вниз */
    flex-direction: column;
    
    /* Вертикально знизу вверх */
    flex-direction: column-reverse;
}

flex-wrap

Визначає, чи можуть flex елементи переноситися на новий рядок.

.container {
    display: flex;
    
    /* Всі елементи в одному рядку (за замовчуванням) */
    flex-wrap: nowrap;
    
    /* Перенос на новий рядок */
    flex-wrap: wrap;
    
    /* Перенос у зворотному порядку */
    flex-wrap: wrap-reverse;
}

/* Скорочена форма flex-direction + flex-wrap */
.container {
    flex-flow: row wrap; /* direction wrap */
}

justify-content

Вирівнювання вздовж головної осі.

.container {
    display: flex;
    
    /* На початку (за замовчуванням) */
    justify-content: flex-start;
    
    /* В кінці */
    justify-content: flex-end;
    
    /* По центру */
    justify-content: center;
    
    /* Рівномірно з відступами між */
    justify-content: space-between;
    
    /* Рівномірно з відступами навколо */
    justify-content: space-around;
    
    /* Рівномірно з однаковими відступами */
    justify-content: space-evenly;
}

align-items

Вирівнювання вздовж поперечної осі (для одного рядка).

.container {
    display: flex;
    
    /* Розтягування на всю висоту (за замовчуванням) */
    align-items: stretch;
    
    /* На початку поперечної осі */
    align-items: flex-start;
    
    /* В кінці поперечної осі */
    align-items: flex-end;
    
    /* По центру поперечної осі */
    align-items: center;
    
    /* По базовій лінії тексту */
    align-items: baseline;
}

align-content

Вирівнювання рядків, коли є flex-wrap: wrap і кілька рядків.

.container {
    display: flex;
    flex-wrap: wrap;
    height: 500px; /* Потрібна фіксована висота */
    
    /* Розтягування рядків (за замовчуванням) */
    align-content: stretch;
    
    /* Рядки на початку */
    align-content: flex-start;
    
    /* Рядки в кінці */
    align-content: flex-end;
    
    /* Рядки по центру */
    align-content: center;
    
    /* Відступи між рядками */
    align-content: space-between;
    
    /* Відступи навколо рядків */
    align-content: space-around;
    
    /* Рівномірні відступи */
    align-content: space-evenly;
}

gap (row-gap, column-gap)

Відступи між flex елементами.

.container {
    display: flex;
    
    /* Відступ між всіма елементами */
    gap: 20px;
    
    /* Різні відступи для рядків та колонок */
    gap: 20px 10px; /* row-gap column-gap */
    
    /* Або окремо */
    row-gap: 20px;
    column-gap: 10px;
}

Властивості Flex елементів

flex-grow

Визначає, скільки вільного простору може зайняти елемент.

.item {
    /* Не збільшується (за замовчуванням) */
    flex-grow: 0;
    
    /* Може збільшуватися */
    flex-grow: 1;
    
    /* Збільшується вдвічі швидше за інші */
    flex-grow: 2;
}

/* Приклад */
.container {
    display: flex;
}

.item-1 {
    flex-grow: 1; /* Займає 1 частину */
}

.item-2 {
    flex-grow: 2; /* Займає 2 частини */
}

.item-3 {
    flex-grow: 1; /* Займає 1 частину */
}
/* Всього 4 частини, item-2 займе 50% вільного простору */

flex-shrink

Визначає, як елемент може зменшуватися.

.item {
    /* Може зменшуватися (за замовчуванням) */
    flex-shrink: 1;
    
    /* Не зменшується */
    flex-shrink: 0;
    
    /* Зменшується швидше */
    flex-shrink: 2;
}

flex-basis

Початковий розмір елемента до розподілу вільного простору.

.item {
    /* Автоматично (за замовчуванням) */
    flex-basis: auto;
    
    /* Фіксований розмір */
    flex-basis: 200px;
    flex-basis: 30%;
    flex-basis: 20em;
    
    /* Розмір контенту */
    flex-basis: content;
    
    /* Нульовий базовий розмір */
    flex-basis: 0;
}

flex (скорочення)

Комбінує flex-grow, flex-shrink і flex-basis.

/* flex: grow shrink basis */

.item {
    /* grow: 0, shrink: 1, basis: auto (за замовчуванням) */
    flex: 0 1 auto;
    
    /* Скорочення для flex: 1 1 0% */
    flex: 1;
    
    /* Не збільшується, не зменшується */
    flex: 0 0 200px;
    
    /* Поширені варіанти */
    flex: auto;     /* 1 1 auto */
    flex: initial;  /* 0 1 auto */
    flex: none;     /* 0 0 auto */
}

/* Практичні приклади */

/* Елемент займає весь доступний простір */
.grow {
    flex: 1;
}

/* Фіксований розмір */
.fixed {
    flex: 0 0 200px;
}

/* Мінімальна ширина з можливістю збільшення */
.min-grow {
    flex: 1 0 100px;
}

order

Змінює порядок відображення елементів.

.item {
    /* За замовчуванням всі мають order: 0 */
    order: 0;
}

.item-1 { order: 2; } /* Відображається третім */
.item-2 { order: 1; } /* Відображається другим */
.item-3 { order: 0; } /* Відображається першим */
.item-4 { order: -1; } /* Відображається самим першим */

align-self

Перевизначає align-items для окремого елемента.

.container {
    display: flex;
    align-items: center; /* Всі по центру */
}

.item-special {
    /* Цей елемент буде на початку */
    align-self: flex-start;
    
    /* Інші значення */
    align-self: flex-end;
    align-self: center;
    align-self: stretch;
    align-self: baseline;
    align-self: auto; /* Використовує значення з контейнера */
}

Практичні приклади компонування

Центрування елемента

/* Найпростіший спосіб центрування */
.container {
    display: flex;
    justify-content: center; /* Горизонтально */
    align-items: center;     /* Вертикально */
    height: 100vh;
}

/* HTML */
<div class="container">
    <div class="centered-box">Я по центру!</div>
</div>

Горизонтальна навігація

.navigation {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 20px;
    background-color: #333;
}

.nav-logo {
    flex: 0 0 auto;
}

.nav-links {
    display: flex;
    gap: 20px;
    list-style: none;
}

/* HTML */
<nav class="navigation">
    <div class="nav-logo">Логотип</div>
    <ul class="nav-links">
        <li><a href="#">Головна</a></li>
        <li><a href="#">Про нас</a></li>
        <li><a href="#">Контакти</a></li>
    </ul>
</nav>

Карткова сітка

.card-grid {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.card {
    flex: 1 1 300px; /* Мінімальна ширина 300px */
    padding: 20px;
    background-color: white;
    border-radius: 8px;
    box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

/* HTML */
<div class="card-grid">
    <div class="card">Картка 1</div>
    <div class="card">Картка 2</div>
    <div class="card">Картка 3</div>
    <div class="card">Картка 4</div>
</div>

Sidebar Layout

.page-layout {
    display: flex;
    min-height: 100vh;
}

.sidebar {
    flex: 0 0 250px;
    background-color: #f5f5f5;
    padding: 20px;
}

.main-content {
    flex: 1; /* Займає весь залишковий простір */
    padding: 20px;
}

/* HTML */
<div class="page-layout">
    <aside class="sidebar">Sidebar</aside>
    <main class="main-content">Main Content</main>
</div>

Sticky Footer

body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
    margin: 0;
}

header {
    flex: 0 0 auto;
    padding: 20px;
    background-color: #333;
}

main {
    flex: 1; /* Займає весь простір між header і footer */
    padding: 20px;
}

footer {
    flex: 0 0 auto;
    padding: 20px;
    background-color: #333;
}

/* HTML */
<body>
    <header>Header</header>
    <main>Content</main>
    <footer>Footer</footer>
</body>

Media Object

.media {
    display: flex;
    gap: 20px;
}

.media-image {
    flex: 0 0 100px; /* Фіксована ширина зображення */
}

.media-image img {
    width: 100%;
    height: auto;
}

.media-content {
    flex: 1; /* Займає весь залишковий простір */
}

/* HTML */
<div class="media">
    <div class="media-image">
        <img src="avatar.jpg" alt="Avatar">
    </div>
    <div class="media-content">
        <h3>Заголовок</h3>
        <p>Опис...</p>
    </div>
</div>

Рівновисокі колонки

.columns {
    display: flex;
    gap: 20px;
}

.column {
    flex: 1; /* Всі колонки однакової ширини */
    padding: 20px;
    background-color: #f5f5f5;
}

/* Колонки автоматично стають однієї висоти! */

/* HTML */
<div class="columns">
    <div class="column">
        <p>Короткий текст</p>
    </div>
    <div class="column">
        <p>Довгий текст...</p>
        <p>Більше контенту...</p>
    </div>
    <div class="column">
        <p>Середній текст</p>
    </div>
</div>

Адаптивний Flexbox

/* Мобільні: вертикально */
.container {
    display: flex;
    flex-direction: column;
    gap: 20px;
}

/* Планшети: 2 колонки */
@media (min-width: 768px) {
    .container {
        flex-direction: row;
        flex-wrap: wrap;
    }
    
    .item {
        flex: 1 1 45%; /* Приблизно 2 в рядку */
    }
}

/* Десктоп: 3+ колонки */
@media (min-width: 1024px) {
    .item {
        flex: 1 1 30%; /* Приблизно 3 в рядку */
    }
}

/* Великі екрани: 4 колонки */
@media (min-width: 1440px) {
    .item {
        flex: 1 1 22%; /* Приблизно 4 в рядку */
    }
}

Holy Grail Layout

body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

header, footer {
    flex: 0 0 auto;
}

main {
    flex: 1;
    display: flex;
}

.sidebar-left {
    flex: 0 0 200px;
}

.content {
    flex: 1;
}

.sidebar-right {
    flex: 0 0 200px;
}

@media (max-width: 768px) {
    main {
        flex-direction: column;
    }
    
    .sidebar-left,
    .sidebar-right {
        flex: 0 0 auto;
    }
}

Flexbox Cheat Sheet

Властивість Застосування Значення
display Контейнер flex | inline-flex
flex-direction Контейнер row | row-reverse | column | column-reverse
flex-wrap Контейнер nowrap | wrap | wrap-reverse
justify-content Контейнер flex-start | flex-end | center | space-between | space-around | space-evenly
align-items Контейнер stretch | flex-start | flex-end | center | baseline
align-content Контейнер stretch | flex-start | flex-end | center | space-between | space-around
gap Контейнер <length>
flex-grow Елемент <number>
flex-shrink Елемент <number>
flex-basis Елемент auto | <length>
flex Елемент <grow> <shrink> <basis>
order Елемент <integer>
align-self Елемент auto | flex-start | flex-end | center | baseline | stretch

Підсумок

Flexbox - потужний інструмент для створення гнучких одновимірних макетів. Використовуйте його для навігації, карток, вирівнювання контенту та створення адаптивних компонентів. Пам'ятайте: flexbox чудово підходить для компонентів та одновимірних макетів, для двовимірних сіток краще використовувати CSS Grid (наступний урок). Комбінуйте властивості контейнера та елементів для досягнення потрібного результату.
