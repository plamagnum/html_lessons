Створення складних таблиць та різних типів списків

Списки в HTML

HTML підтримує три основних типи списків: нумеровані, ненумеровані та списки визначень. Кожен тип має своє призначення та особливості використання.

Ненумерований список (Unordered List)

Використовується для елементів без певного порядку. Позначається маркерами.

<ul>
    <li>Яблука</li>
    <li>Банани</li>
    <li>Апельсини</li>
</ul>

Нумерований список (Ordered List)

Використовується для елементів з певним порядком. Позначається числами.

<ol>
    <li>Розігрійте духовку до 180°C</li>
    <li>Змішайте інгредієнти</li>
    <li>Випікайте 30 хвилин</li>
</ol>

<!-- Список з іншим типом нумерації -->
<ol type="A">
    <li>Пункт A</li>
    <li>Пункт B</li>
</ol>

<!-- Початок з певного числа -->
<ol start="5">
    <li>Пункт 5</li>
    <li>Пункт 6</li>
</ol>

Вкладені списки

Списки можна вкладати один в одного для створення ієрархічної структури.

<ul>
    <li>Фрукти
        <ul>
            <li>Яблука
                <ul>
                    <li>Зелені</li>
                    <li>Червоні</li>
                </ul>
            </li>
            <li>Банани</li>
        </ul>
    </li>
    <li>Овочі
        <ul>
            <li>Помідори</li>
            <li>Огірки</li>
        </ul>
    </li>
</ul>

Список визначень (Description List)

Використовується для пар термін-визначення, як у словнику або глосарії. Складається з <dl> (description list), <dt> (term) та <dd> (definition). 

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language - мова розмітки гіпертексту</dd>
    
    <dt>CSS</dt>
    <dd>Cascading Style Sheets - каскадні таблиці стилів</dd>
    
    <dt>JavaScript</dt>
    <dd>Мова програмування для веб-розробки</dd>
    <dd>Працює у браузері та на сервері (Node.js)</dd>
</dl>

Практичне застосування списків визначень

  • Глосарії та словники
  • Метадані та властивості об'єктів
  • FAQ секції
  • Описи продуктів

Таблиці в HTML

Таблиці використовуються для представлення табличних даних. Основні теги: <table>, <tr> (рядок), <th> (заголовок), <td> (комірка).

Проста таблиця

<table>
    <thead>
        <tr>
            <th>Ім'я</th>
            <th>Вік</th>
            <th>Місто</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Іван</td>
            <td>25</td>
            <td>Київ</td>
        </tr>
        <tr>
            <td>Марія</td>
            <td>30</td>
            <td>Львів</td>
        </tr>
    </tbody>
</table>

Об'єднання комірок: colspan та rowspan

Атрибут colspan об'єднує комірки по горизонталі, а rowspan - по вертикалі. 

<table border="1">
    <thead>
        <tr>
            <th colspan="3">Розклад занять</th>
        </tr>
        <tr>
            <th>Час</th>
            <th>Понеділок</th>
            <th>Вівторок</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>9:00</td>
            <td rowspan="2">Математика</td>
            <td>Фізика</td>
        </tr>
        <tr>
            <td>10:00</td>
            <td>Хімія</td>
        </tr>
        <tr>
            <td>11:00</td>
            <td colspan="2">Перерва</td>
        </tr>
    </tbody>
</table>

Структура складної таблиці

Правильна структура таблиці включає <thead>, <tbody>, та <tfoot> для кращої семантики та доступності. 

<table>
    <caption>Квартальний звіт продажів</caption>
    <thead>
        <tr>
            <th scope="col">Місяць</th>
            <th scope="col">Продажі</th>
            <th scope="col">Прибуток</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">Січень</th>
            <td>100 000 грн</td>
            <td>25 000 грн</td>
        </tr>
        <tr>
            <th scope="row">Лютий</th>
            <td>120 000 грн</td>
            <td>30 000 грн</td>
        </tr>
        <tr>
            <th scope="row">Березень</th>
            <td>150 000 грн</td>
            <td>37 500 грн</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <th scope="row">Всього</th>
            <td>370 000 грн</td>
            <td>92 500 грн</td>
        </tr>
    </tfoot>
</table>

Важливі атрибути таблиць

  • scope="col" або scope="row" - вказує область дії заголовка
  • <caption> - надає заголовок таблиці
  • colspan - кількість колонок для об'єднання
  • rowspan - кількість рядків для об'єднання

Практичний приклад: Складна таблиця

<table>
    <caption>Порівняння тарифних планів</caption>
    <thead>
        <tr>
            <th rowspan="2">Функція</th>
            <th colspan="3">Тарифні плани</th>
        </tr>
        <tr>
            <th>Базовий</th>
            <th>Стандарт</th>
            <th>Преміум</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">Вартість/міс</th>
            <td>99 грн</td>
            <td>199 грн</td>
            <td>399 грн</td>
        </tr>
        <tr>
            <th scope="row">Користувачі</th>
            <td>1</td>
            <td>5</td>
            <td>Необмежено</td>
        </tr>
        <tr>
            <th scope="row">Сховище</th>
            <td>10 GB</td>
            <td>100 GB</td>
            <td>1 TB</td>
        </tr>
        <tr>
            <th scope="row">Підтримка</th>
            <td>Email</td>
            <td colspan="2">Email + Телефон 24/7</td>
        </tr>
    </tbody>
</table>

Групування колонок: colgroup

Елемент <colgroup> дозволяє застосовувати стилі до цілих колонок. 

<table>
    <colgroup>
        <col style="background-color: #f0f0f0;">
        <col span="2" style="background-color: #e0f7fa;">
        <col style="background-color: #fff3e0;">
    </colgroup>
    <thead>
        <tr>
            <th>Назва</th>
            <th>Q1</th>
            <th>Q2</th>
            <th>Всього</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Продукт A</td>
            <td>1000</td>
            <td>1200</td>
            <td>2200</td>
        </tr>
    </tbody>
</table>

Підсумок

Списки та таблиці - фундаментальні елементи HTML для структурування інформації. Використовуйте відповідний тип списку для кожної ситуації, а для табличних даних створюйте семантично правильні таблиці з заголовками, підписами та правильною структурою. Це покращує доступність та SEO вашого сайту.
