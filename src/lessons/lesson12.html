Урок 12: CSS змінні та адаптивний дизайн

Використання CSS змінних та створення адаптивних макетів

CSS Custom Properties (Змінні)

CSS змінні (Custom Properties) дозволяють зберігати значення для повторного використання. Це робить код більш підтримуваним та гнучким.

Оголошення та використання змінних

/* Оголошуємо глобальні змінні в :root */
:root {
    --primary-color: #3498db;
    --secondary-color: #2ecc71;
    --text-color: #333;
    --background-color: #f5f5f5;
    --spacing-unit: 8px;
    --border-radius: 4px;
    --font-size-base: 16px;
    --font-family: 'Arial', sans-serif;
}

/* Використовуємо змінні через var() */
.button {
    background-color: var(--primary-color);
    color: white;
    padding: calc(var(--spacing-unit) * 2);
    border-radius: var(--border-radius);
    font-size: var(--font-size-base);
    font-family: var(--font-family);
}

.button:hover {
    background-color: var(--secondary-color);
}

Локальні змінні та перевизначення

/* Глобальні змінні */
:root {
    --button-bg: #3498db;
    --button-padding: 10px 20px;
}

/* Локальне перевизначення */
.button-large {
    --button-padding: 15px 30px;  /* перевизначаємо тільки тут */
    background-color: var(--button-bg);
    padding: var(--button-padding);
}

.button-small {
    --button-padding: 5px 10px;
    background-color: var(--button-bg);
    padding: var(--button-padding);
}

Fallback значення

/* Якщо --primary-color не визначена, використається #3498db */
.element {
    color: var(--primary-color, #3498db);
}

/* Вкладені fallback */
.element {
    color: var(--text-color, var(--default-color, #000));
}

Практичний приклад: Тема сайту

/* Світла тема (за замовчуванням) */
:root {
    --bg-primary: #ffffff;
    --bg-secondary: #f8f9fa;
    --text-primary: #212529;
    --text-secondary: #6c757d;
    --border-color: #dee2e6;
    --accent-color: #007bff;
}

/* Темна тема */
[data-theme="dark"] {
    --bg-primary: #1a1a1a;
    --bg-secondary: #2d2d2d;
    --text-primary: #ffffff;
    --text-secondary: #b0b0b0;
    --border-color: #404040;
    --accent-color: #4d94ff;
}

/* Використання змінних */
body {
    background-color: var(--bg-primary);
    color: var(--text-primary);
}

.card {
    background-color: var(--bg-secondary);
    border: 1px solid var(--border-color);
    color: var(--text-primary);
}

.link {
    color: var(--accent-color);
}

Адаптивний дизайн (Responsive Design)

Адаптивний дизайн забезпечує коректне відображення сайту на пристроях різних розмірів - від мобільних телефонів до великих моніторів.

Основні принципи адаптивного дизайну

  • Mobile First - спочатку дизайн для мобільних, потім для великих екранів
  • Гнучкі макети - використання відносних одиниць (%, em, rem, vh, vw)
  • Гнучкі зображення - max-width: 100% для адаптації розмірів
  • Media Queries - різні стилі для різних розмірів екранів

Media Queries

Media queries дозволяють застосовувати різні стилі залежно від характеристик пристрою.

Базовий синтаксис

/* Стилі для всіх екранів */
.container {
    width: 100%;
    padding: 20px;
}

/* Стилі для екранів шириною від 768px */
@media (min-width: 768px) {
    .container {
        width: 750px;
        margin: 0 auto;
    }
}

/* Стилі для екранів шириною від 1024px */
@media (min-width: 1024px) {
    .container {
        width: 960px;
    }
}

/* Стилі для екранів шириною від 1200px */
@media (min-width: 1200px) {
    .container {
        width: 1140px;
    }
}

Стандартні breakpoints

/* Extra small devices (phones, less than 576px) */
/* За замовчуванням, без media query */

/* Small devices (landscape phones, 576px and up) */
@media (min-width: 576px) { }

/* Medium devices (tablets, 768px and up) */
@media (min-width: 768px) { }

/* Large devices (desktops, 992px and up) */
@media (min-width: 992px) { }

/* Extra large devices (large desktops, 1200px and up) */
@media (min-width: 1200px) { }

/* XXL devices (larger desktops, 1400px and up) */
@media (min-width: 1400px) { }

Різні умови в media queries

/* Ширина екрану */
@media (min-width: 768px) { }  /* від 768px і більше */
@media (max-width: 767px) { }  /* до 767px включно */
@media (min-width: 768px) and (max-width: 1024px) { }  /* діапазон */

/* Орієнтація */
@media (orientation: portrait) { }   /* вертикальна */
@media (orientation: landscape) { }  /* горизонтальна */

/* Щільність пікселів (Retina екрани) */
@media (-webkit-min-device-pixel-ratio: 2),
       (min-resolution: 192dpi) { }

/* Комбінування умов */
@media (min-width: 768px) and (orientation: landscape) { }

/* Логічний оператор OR */
@media (max-width: 767px), (orientation: portrait) { }

Mobile-First підхід

Mobile-First означає, що базові стилі пишуться для мобільних пристроїв, а через media queries додаються покращення для більших екранів. 

/* Базові стилі для мобільних (mobile-first) */
.grid {
    display: grid;
    grid-template-columns: 1fr;  /* 1 колонка на мобільних */
    gap: 15px;
    padding: 15px;
}

.card {
    padding: 15px;
    font-size: 14px;
}

/* Планшети - 2 колонки */
@media (min-width: 768px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
        gap: 20px;
        padding: 20px;
    }
    
    .card {
        padding: 20px;
        font-size: 16px;
    }
}

/* Десктопи - 3 колонки */
@media (min-width: 1024px) {
    .grid {
        grid-template-columns: repeat(3, 1fr);
        gap: 30px;
        padding: 30px;
    }
}

/* Великі екрани - 4 колонки */
@media (min-width: 1400px) {
    .grid {
        grid-template-columns: repeat(4, 1fr);
    }
}

Адаптивна типографіка

/* Використання clamp() для плавної зміни розміру */
h1 {
    font-size: clamp(1.5rem, 4vw, 3rem);
    /* min: 1.5rem, ideal: 4vw, max: 3rem */
}

/* Адаптивний розмір через media queries */
body {
    font-size: 14px;
}

@media (min-width: 768px) {
    body { font-size: 16px; }
}

@media (min-width: 1024px) {
    body { font-size: 18px; }
}

/* Використання rem з адаптивним базовим розміром */
html {
    font-size: 14px;  /* 1rem = 14px */
}

@media (min-width: 768px) {
    html { font-size: 16px; }  /* 1rem = 16px */
}

h1 { font-size: 2rem; }    /* 28px на мобільних, 32px на десктопі */
h2 { font-size: 1.5rem; }  /* 21px на мобільних, 24px на десктопі */

Адаптивні зображення

/* Базове адаптивне зображення */
img {
    max-width: 100%;
    height: auto;
    display: block;
}

/* Різні зображення для різних розмірів */
<picture>
    <source media="(min-width: 1024px)" srcset="image-large.jpg">
    <source media="(min-width: 768px)" srcset="image-medium.jpg">
    <img src="image-small.jpg" alt="Опис">
</picture>

/* Використання srcset для різної щільності пікселів */
<img 
    src="image-1x.jpg" 
    srcset="image-1x.jpg 1x, image-2x.jpg 2x, image-3x.jpg 3x"
    alt="Опис"
>

/* CSS для адаптивних фонових зображень */
.hero {
    background-image: url('hero-small.jpg');
    background-size: cover;
    background-position: center;
}

@media (min-width: 768px) {
    .hero {
        background-image: url('hero-medium.jpg');
    }
}

@media (min-width: 1024px) {
    .hero {
        background-image: url('hero-large.jpg');
    }
}

Комплексний приклад: Адаптивна навігація

<style>
:root {
    --nav-bg: #2c3e50;
    --nav-text: #ecf0f1;
    --nav-hover: #3498db;
}

/* Мобільна навігація */
.navbar {
    background-color: var(--nav-bg);
    padding: 1rem;
}

.nav-toggle {
    display: block;
    background: none;
    border: none;
    color: var(--nav-text);
    font-size: 1.5rem;
    cursor: pointer;
}

.nav-menu {
    display: none;  /* приховано на мобільних */
    flex-direction: column;
    gap: 0;
}

.nav-menu.active {
    display: flex;
}

.nav-link {
    display: block;
    color: var(--nav-text);
    padding: 1rem;
    text-decoration: none;
    border-top: 1px solid rgba(255,255,255,0.1);
}

.nav-link:hover {
    background-color: var(--nav-hover);
}

/* Планшети та десктопи */
@media (min-width: 768px) {
    .nav-toggle {
        display: none;  /* приховуємо кнопку меню */
    }
    
    .nav-menu {
        display: flex !important;  /* завжди видиме */
        flex-direction: row;
        gap: 1rem;
    }
    
    .nav-link {
        border-top: none;
        padding: 0.5rem 1rem;
        border-radius: 4px;
    }
}
</style>

Сучасні CSS одиниці виміру

/* Viewport одиниці */
.full-height {
    height: 100vh;  /* 100% висоти viewport */
    width: 100vw;   /* 100% ширини viewport */
}

.hero {
    min-height: 50vh;  /* мінімум 50% висоти екрану */
}

/* Container Query Units (нові!) */
.card {
    font-size: 2cqw;  /* 2% від ширини контейнера */
}

/* Відносні одиниці */
.element {
    font-size: 1rem;      /* відносно root font-size */
    padding: 2em;         /* відносно власного font-size */
    margin: 5%;           /* відносно ширини батьківського елемента */
}

/* Calc для обчислень */
.sidebar {
    width: calc(100% - 300px);
    height: calc(100vh - 80px);
}

/* Min/Max функції */
.container {
    width: min(90%, 1200px);  /* менше з двох значень */
    padding: max(20px, 3vw);  /* більше з двох значень */
}

/* Clamp - комбінація min, ideal, max */
.title {
    font-size: clamp(1.5rem, 5vw, 3rem);
    /* не менше 1.5rem, не більше 3rem, в ідеалі 5vw */
}

Container Queries (Нова можливість!)

/* Визначаємо контейнер */
.sidebar {
    container-type: inline-size;
    container-name: sidebar;
}

/* Стилі залежно від розміру контейнера, а не viewport */
.card {
    padding: 1rem;
}

@container sidebar (min-width: 400px) {
    .card {
        display: grid;
        grid-template-columns: 1fr 2fr;
        padding: 2rem;
    }
}

/* Це краще ніж media queries для компонентів! */

Підсумок

CSS змінні роблять ваш код гнучким та легким у підтримці. Адаптивний дизайн з mobile-first підходом та media queries забезпечує відмінний досвід на всіх пристроях. Використовуйте сучасні одиниці виміру (vw, vh, clamp) та нові можливості як container queries для створення справді адаптивних інтерфейсів.
