Урок 7: Посилання та навігація

Якірні посилання, шляхи, атрибути та навігаційні патерни

Основи посилань

Елемент <a> (anchor) створює гіперпосилання - основу навігації в інтернеті.

Базовий синтаксис

<!-- Просте посилання -->
<a href="https://example.com">Відвідати сайт</a>

<!-- Посилання з підказкою -->
<a href="https://example.com" title="Перейти на example.com">
    Відвідати сайт
</a>

<!-- Посилання на email -->
<a href="mailto:info@example.com">Написати нам</a>

<!-- Посилання на телефон -->
<a href="tel:+380123456789">+380 12 345 67 89</a>

Абсолютні та відносні шляхи

Абсолютні URL

Повний шлях до ресурсу, включаючи протокол та домен.

<!-- Зовнішнє посилання -->
<a href="https://www.google.com">Google</a>

<!-- З портом -->
<a href="http://localhost:3000/api">API</a>

<!-- Безпечне з'єднання -->
<a href="https://secure.example.com/login">Вхід</a>

Відносні URL

Шлях відносно поточного документа або кореневої директорії.

<!-- Відносно поточної сторінки -->
<a href="about.html">Про нас</a>
<a href="pages/contact.html">Контакти</a>

<!-- Повернутися на рівень вище -->
<a href="../index.html">Головна</a>
<a href="../../docs/guide.pdf">Гід</a>

<!-- Відносно кореня сайту (починається з /) -->
<a href="/products">Продукти</a>
<a href="/blog/article-1">Стаття</a>

<!-- Поточна директорія -->
<a href="./page.html">Сторінка</a>

Коли використовувати який шлях?

  • Абсолютні: посилання на інші сайти
  • Відносні від кореня (/): навігація всередині сайту
  • Відносні: посилання на сусідні файли

Якірні посилання (Anchors)

Посилання на конкретні місця на сторінці за допомогою ID.

<!-- Посилання на якір -->
<a href="#section1">Перейти до секції 1</a>
<a href="#contacts">До контактів</a>

<!-- Якір на тій же сторінці -->
<nav>
    <a href="#about">Про нас</a>
    <a href="#services">Послуги</a>
    <a href="#portfolio">Портфоліо</a>
    <a href="#contacts">Контакти</a>
</nav>

<!-- Секції з ID -->
<section id="about">
    <h2>Про нас</h2>
    <p>Контент...</p>
</section>

<section id="services">
    <h2>Послуги</h2>
    <p>Контент...</p>
</section>

<!-- Повернутися до початку -->
<a href="#">Вгору</a>
<a href="#top">До початку</a>

<!-- Якір на іншій сторінці -->
<a href="page2.html#section3">Секція 3 на сторінці 2</a>

Атрибут target

Визначає, де відкриється посилання.

<!-- Відкрити в новій вкладці -->
<a href="https://example.com" target="_blank">
    Зовнішнє посилання
</a>

<!-- Відкрити в тому ж вікні (за замовчуванням) -->
<a href="page.html" target="_self">Та ж вкладка</a>

<!-- Відкрити в батьківському фреймі -->
<a href="page.html" target="_parent">Батьківський фрейм</a>

<!-- Відкрити в повному вікні -->
<a href="page.html" target="_top">Повне вікно</a>

<!-- Відкрити в іменованому вікні/вкладці -->
<a href="page.html" target="myWindow">Нове вікно</a>

Безпека з target="_blank"

При використанні target="_blank" додавайте rel="noopener noreferrer" для безпеки:

<a href="https://external-site.com" 
   target="_blank" 
   rel="noopener noreferrer">
    Безпечне зовнішнє посилання
</a>

Атрибут rel

Визначає відношення між поточним документом та ресурсом.

<!-- Зовнішнє посилання -->
<a href="https://example.com" rel="external">Зовнішній сайт</a>

<!-- Не передавати реферер -->
<a href="https://example.com" rel="noreferrer">Без реферера</a>

<!-- Не впливати на SEO -->
<a href="https://example.com" rel="nofollow">Посилання nofollow</a>

<!-- Безпека для нової вкладки -->
<a href="https://example.com" 
   target="_blank" 
   rel="noopener noreferrer">
    Безпечне посилання
</a>

<!-- Спонсорське посилання -->
<a href="https://sponsor.com" rel="sponsored">Спонсор</a>

<!-- UGC (User Generated Content) -->
<a href="https://user-site.com" rel="ugc">Посилання користувача</a>

<!-- Комбінація -->
<a href="https://example.com" 
   rel="nofollow noopener noreferrer external">
    Посилання з кількома rel
</a>

Атрибут download

Пропонує завантажити файл замість відкриття.

<!-- Завантажити файл з оригінальним ім'ям -->
<a href="/files/document.pdf" download>
    Завантажити PDF
</a>

<!-- Завантажити з новим ім'ям -->
<a href="/files/report-2024.xlsx" download="financial-report.xlsx">
    Завантажити звіт
</a>

<!-- Завантажити зображення -->
<a href="/images/photo.jpg" download="my-photo.jpg">
    Завантажити фото
</a>

Email та телефонні посилання

Mailto посилання

<!-- Простий email -->
<a href="mailto:info@example.com">Написати нам</a>

<!-- З темою -->
<a href="mailto:support@example.com?subject=Підтримка">
    Техпідтримка
</a>

<!-- З темою та текстом -->
<a href="mailto:sales@example.com?subject=Запит&body=Доброго дня!">
    Запит продажу
</a>

<!-- З копіями -->
<a href="mailto:info@example.com?cc=manager@example.com&bcc=archive@example.com">
    З копіями
</a>

<!-- Повний приклад -->
<a href="mailto:contact@example.com?subject=Питання%20про%20продукт&body=Доброго%20дня!%0A%0AХочу%20дізнатися...">
    Запитати про продукт
</a>

Телефонні посилання

<!-- Простий телефон -->
<a href="tel:+380123456789">+380 12 345 67 89</a>

<!-- Без пробілів та дефісів в href -->
<a href="tel:+380987654321">+380 98 765 43 21</a>

<!-- З додатковим номером -->
<a href="tel:+380123456789,123">+380 12 345 67 89 (доб. 123)</a>

SMS посилання

<!-- SMS -->
<a href="sms:+380123456789">Надіслати SMS</a>

<!-- SMS з текстом -->
<a href="sms:+380123456789?body=Доброго%20дня!">
    Швидке SMS
</a>

Навігаційні патерни

Головна навігація

<header>
    <nav aria-label="Головна навігація">
        <ul>
            <li><a href="/" aria-current="page">Головна</a></li>
            <li><a href="/about">Про нас</a></li>
            <li><a href="/services">Послуги</a></li>
            <li><a href="/portfolio">Портфоліо</a></li>
            <li><a href="/contact">Контакти</a></li>
        </ul>
    </nav>
</header>

Навігація з підменю

<nav>
    <ul>
        <li>
            <a href="/products">Продукти</a>
            <ul>
                <li><a href="/products/web">Веб-розробка</a></li>

Хлібні крихти (Breadcrumbs)

<nav aria-label="Breadcrumb">
    <ol>
        <li><a href="/">Головна</a></li>
        <li><a href="/products">Продукти</a></li>
        <li><a href="/products/laptops">Ноутбуки</a></li>
        <li aria-current="page">MacBook Pro 16</li>

</nav>

Стилізація посилань

/* Стани посилань */
a:link {
    color: #3498db;
    text-decoration: none;
}

a:visited {
    color: #9b59b6;
}

a:hover {
    color: #2980b9;
    text-decoration: underline;
}

a:active {
    color: #e74c3c;
}

a:focus {
    outline: 2px solid #3498db;
    outline-offset: 2px;
}

/* Кнопка-посилання */
.button-link {
    display: inline-block;
    padding: 10px 20px;
    background-color: #3498db;
    color: white;
    border-radius: 5px;
    transition: background-color 0.3s;
}

.button-link:hover {
    background-color: #2980b9;
    text-decoration: none;
}

/* Зовнішні посилання з іконкою */
a[target="_blank"]::after {
    content: " ↗";
    font-size: 0.8em;
}

/* Посилання для завантаження */
a[download]::before {
    content: "⬇ ";
}

Підсумок

Посилання - основа веб-навігації. Використовуйте відповідні шляхи (абсолютні/відносні), додавайте rel="noopener noreferrer" до зовнішніх посилань з target="_blank", створюйте якірні посилання для навігації по сторінці, використовуйте семантичні елементи <nav> та атрибути aria-label для доступності. Правильна навігаційна структура покращує користувацький досвід та SEO.
