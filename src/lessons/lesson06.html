Урок 6: Meta-теги та SEO

Оптимізація для пошукових систем та соціальних мереж

Основні Meta-теги

Meta-теги надають інформацію про HTML-документ. Вони розміщуються в <head> секції і не відображаються на сторінці, але важливі для пошукових систем, браузерів та соціальних мереж.

Базова структура head

<head>
    <!-- Кодування -->
    <meta charset="UTF-8">
    
    <!-- Viewport для адаптивного дизайну -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- Заголовок сторінки (найважливіший для SEO) -->
    <title>Назва вашої сторінки - Назва сайту</title>
    
    <!-- Опис сторінки -->
    <meta name="description" 
          content="Короткий опис вашої сторінки (150-160 символів)">
    
    <!-- Ключові слова (менш важливі зараз) -->
    <meta name="keywords" content="html, css, javascript, навчання">
    
    <!-- Автор -->
    <meta name="author" content="Ім'я Автора">
</head>

Viewport та адаптивність

Meta-тег viewport критично важливий для мобільних пристроїв. 

<!-- Стандартний viewport -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<!-- З обмеженням масштабування -->
<meta name="viewport" 
      content="width=device-width, initial-scale=1.0, 
               maximum-scale=5.0, minimum-scale=1.0">

<!-- Заборона масштабування (не рекомендується) -->
<meta name="viewport" 
      content="width=device-width, initial-scale=1.0, user-scalable=no">

Параметри viewport

  • width=device-width - ширина відповідає пристрою
  • initial-scale=1.0 - початковий масштаб 100%
  • maximum-scale - максимальний масштаб
  • minimum-scale - мінімальний масштаб
  • user-scalable - дозвіл масштабування (yes/no)

SEO Meta-теги

Robots (керування індексацією)

<!-- Дозволити індексацію та переходи по посиланнях -->
<meta name="robots" content="index, follow">

<!-- Заборонити індексацію -->
<meta name="robots" content="noindex, nofollow">

<!-- Не зберігати кеш -->
<meta name="robots" content="noarchive">

<!-- Не показувати сніпет -->
<meta name="robots" content="nosnippet">

<!-- Комбінація -->
<meta name="robots" content="index, follow, max-snippet:-1, max-image-preview:large">

Canonical URL (канонічне посилання)

<!-- Вказує на основну версію сторінки -->
<link rel="canonical" href="https://example.com/original-page">

Альтернативні мови

<!-- Мова документа -->
<html lang="uk">

<!-- Альтернативні мовні версії -->
<link rel="alternate" hreflang="uk" href="https://example.com/uk/">
<link rel="alternate" hreflang="en" href="https://example.com/en/">
<link rel="alternate" hreflang="pl" href="https://example.com/pl/">
<link rel="alternate" hreflang="x-default" href="https://example.com/">

Open Graph (Facebook, LinkedIn)

Open Graph теги контролюють, як ваша сторінка відображається при поширенні в соціальних мережах. 

<!-- Базові OG теги -->
<meta property="og:title" content="Назва вашої сторінки">
<meta property="og:description" content="Опис для соціальних мереж">
<meta property="og:image" content="https://example.com/image.jpg">
<meta property="og:url" content="https://example.com/page">
<meta property="og:type" content="website">

<!-- Додаткові OG теги -->
<meta property="og:site_name" content="Назва вашого сайту">
<meta property="og:locale" content="uk_UA">
<meta property="og:locale:alternate" content="en_US">

<!-- Розміри зображення -->
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Опис зображення">

<!-- Для статей -->
<meta property="og:type" content="article">
<meta property="article:published_time" content="2024-01-15T10:00:00Z">
<meta property="article:author" content="Ім'я Автора">
<meta property="article:section" content="Технології">
<meta property="article:tag" content="HTML">
<meta property="article:tag" content="SEO">

Twitter Cards

Twitter має власні meta-теги для контролю відображення в стрічці. 

<!-- Summary Card -->
<meta name="twitter:card" content="summary">
<meta name="twitter:site" content="@username">
<meta name="twitter:creator" content="@username">
<meta name="twitter:title" content="Назва сторінки">
<meta name="twitter:description" content="Опис сторінки">
<meta name="twitter:image" content="https://example.com/image.jpg">

<!-- Large Image Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Назва">
<meta name="twitter:description" content="Опис">
<meta name="twitter:image" content="https://example.com/large-image.jpg">

Типи Twitter Cards

  • summary - маленьке зображення (квадратне)
  • summary_large_image - велике зображення (2:1)
  • app - для мобільних додатків
  • player - для відео/аудіо контенту

Favicon та іконки

<!-- Стандартний favicon -->
<link rel="icon" type="image/x-icon" href="/favicon.ico">

<!-- PNG favicon різних розмірів -->
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="192x192" href="/favicon-192x192.png">

<!-- Apple Touch Icon -->
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

<!-- Android Chrome -->
<link rel="manifest" href="/site.webmanifest">

<!-- Safari Pinned Tab -->
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#5bbad5">

<!-- Теми браузера -->
<meta name="theme-color" content="#ffffff">
<meta name="msapplication-TileColor" content="#da532c">

Schema.org Structured Data

Структуровані дані допомагають пошуковим системам краще розуміти контент.

JSON-LD для організації

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Моя компанія",
  "url": "https://example.com",
  "logo": "https://example.com/logo.png",
  "contactPoint": {
    "@type": "ContactPoint",
    "telephone": "+380-XX-XXX-XXXX",
    "contactType": "customer service",
    "availableLanguage": ["Ukrainian", "English"]
  },
  "sameAs": [
    "https://facebook.com/mycompany",
    "https://twitter.com/mycompany",
    "https://linkedin.com/company/mycompany"
  ]
}
</script>

Повний приклад оптимізованого head

<!DOCTYPE html>
<html lang="uk">
<head>
    <!-- Базові meta теги -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- SEO -->
    <title>Повний гід по HTML та CSS - WebDev Academy</title>
    <meta name="description" 
          content="Навчіться HTML та CSS з нуля. Повний курс для початківців з практичними прикладами та завданнями.">
    <meta name="keywords" content="HTML, CSS, навчання, курс, веб-розробка">
    <meta name="author" content="WebDev Academy">
    <link rel="canonical" href="https://webdev.example.com/html-css-guide">
    
    <!-- Robots -->
    <meta name="robots" content="index, follow, max-snippet:-1, max-image-preview:large">
    
    <!-- Альтернативні мови -->
    <link rel="alternate" hreflang="uk" href="https://webdev.example.com/uk/html-css-guide">
    <link rel="alternate" hreflang="en" href="https://webdev.example.com/en/html-css-guide">
    
    <!-- Open Graph -->
    <meta property="og:title" content="Повний гід по HTML та CSS">
    <meta property="og:description" content="Навчіться веб-розробці з нуля">
    <meta property="og:image" content="https://webdev.example.com/og-image.jpg">
    <meta property="og:image:width" content="1200">
    <meta property="og:image:height" content="630">
    <meta property="og:url" content="https://webdev.example.com/html-css-guide">
    <meta property="og:type" content="article">
    <meta property="og:site_name" content="WebDev Academy">
    <meta property="og:locale" content="uk_UA">
    
    <!-- Twitter -->
    <meta name="twitter:card" content="summary_large_image">
    <meta name="twitter:site" content="@webdevacademy">
    <meta name="twitter:title" content="Повний гід по HTML та CSS">
    <meta name="twitter:description" content="Навчіться веб-розробці з нуля">
    <meta name="twitter:image" content="https://webdev.example.com/twitter-image.jpg">
    
    <!-- Favicon -->
    <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
    <link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
    <link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
    <link rel="manifest" href="/site.webmanifest">
    <meta name="theme-color" content="#3498db">
    
    <!-- Structured Data -->
    <script type="application/ld+json">
    {
      "@context": "https://schema.org",
      "@type": "Course",
      "name": "Повний гід по HTML та CSS",
      "description": "Навчіться HTML та CSS з нуля",
      "provider": {
        "@type": "Organization",
        "name": "WebDev Academy"
      }
    }
    </script>
    
    <!-- Stylesheets -->
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <!-- Контент сторінки -->
</body>
</html>

Інструменти для перевірки SEO

Корисні інструменти

  • Google Search Console - аналіз присутності в Google
  • Facebook Sharing Debugger - перевірка Open Graph
  • Twitter Card Validator - перевірка Twitter Cards
  • Schema.org Validator - перевірка структурованих даних
  • PageSpeed Insights - швидкість завантаження
  • Mobile-Friendly Test - тест мобільної версії

Підсумок

Правильна конфігурація meta-тегів критично важлива для SEO та присутності в соціальних мережах. Завжди додавайте viewport для адаптивності, заповнюйте Open Graph та Twitter Cards для красивого відображення при поширенні, використовуйте структуровані дані для кращого розуміння контенту пошуковими системами. Пам'ятайте про унікальні title та description для кожної сторінки.
