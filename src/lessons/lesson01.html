Урок 1: Семантичний HTML5

Розуміння та використання семантичних тегів

Що таке семантичний HTML?

Семантичний HTML означає використання HTML-тегів, які чітко описують своє призначення та зміст. Замість того, щоб використовувати загальні теги як <div> та <span> для всього, ми використовуємо специфічні теги, що описують структуру документа.

Чому семантика важлива?

  • SEO: Пошукові системи краще розуміють структуру вашого контенту
  • Доступність: Скрін-рідери можуть краще навігувати по сторінці
  • Читабельність коду: Розробникам легше розуміти структуру сторінки
  • Підтримка: Код стає більш зрозумілим та легшим у підтримці

Основні семантичні теги HTML5

<header> - Шапка сторінки або секції

Містить вступну інформацію, логотип, навігацію тощо.

<header>
    <h1>Моя веб-сторінка</h1>
    <nav>
        <a href="#home">Головна</a>
        <a href="#about">Про нас</a>
    </nav>
</header>

<nav> - Навігаційна секція

Використовується для основних навігаційних посилань.

<nav>
    <ul>
        <li><a href="/">Головна</a></li>
        <li><a href="/products">Продукти</a></li>
        <li><a href="/contact">Контакти</a></li>
    </ul>
</nav>

<main> - Головний контент

Містить основний унікальний контент документа. На сторінці має бути тільки один тег <main>.

<main>
    <h1>Заголовок статті</h1>
    <p>Основний контент статті...</p>
</main>

<section> - Тематична секція

Групує пов'язаний контент. Зазвичай має власний заголовок.

<section>
    <h2>Наші послуги</h2>
    <p>Опис послуг...</p>
</section>

<article> - Незалежна стаття

Самостійний контент, який може бути розповсюджений окремо (стаття блогу, новина, коментар).

<article>
    <h2>Назва статті</h2>
    <p>Автор: Іван Іваненко</p>
    <p>Текст статті...</p>
</article>

<aside> - Додатковий контент

Контент, пов'язаний з основним, але може існувати окремо (sidebar, реклама, пов'язані статті).

<aside>
    <h3>Пов'язані статті</h3>
    <ul>
        <li><a href="#">Стаття 1</a></li>
        <li><a href="#">Стаття 2</a></li>
    </ul>
</aside>

<footer> - Підвал сторінки або секції

Містить інформацію про автора, копірайт, посилання на документи тощо.

<footer>
    <p>© 2024 Моя компанія. Всі права захищені.</p>
    <p>Контакт: info@example.com</p>
</footer>

Повний приклад семантичної структури

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Семантична сторінка</title>
</head>
<body>
    <header>
        <h1>Мій блог</h1>
        <nav>
            <a href="#home">Головна</a>
            <a href="#blog">Блог</a>
            <a href="#contact">Контакт</a>
        </nav>
    </header>
    
    <main>
        <article>
            <h2>Вивчаємо HTML5</h2>
            <p>Опубліковано: 1 січня 2024</p>
            <section>
                <h3>Вступ</h3>
                <p>HTML5 приніс багато нових можливостей...</p>
            </section>
            <section>
                <h3>Семантичні теги</h3>
                <p>Використання правильних тегів важливе...</p>
            </section>
        </article>
        
        <aside>
            <h3>Рекомендовані статті</h3>
            <ul>
                <li><a href="#">CSS для початківців</a></li>
                <li><a href="#">JavaScript основи</a></li>
            </ul>
        </aside>
    </main>
    
    <footer>
        <p>© 2024 Мій блог</p>
    </footer>
</body>
</html>

Додаткові семантичні теги

Тег Призначення
<figure> Контейнер для ілюстрацій, діаграм, фото з підписом
<figcaption> Підпис до figure
<time> Дата або час
<mark> Виділений (підсвічений) текст
<details> Деталі, які користувач може показати або сховати
<summary> Видимий заголовок для details

Підсумок

Семантичний HTML робить ваш код більш структурованим, зрозумілим та доступним. Використовуйте відповідні теги для відповідного контенту, і ваші веб-сторінки будуть краще індексуватися пошуковими системами та будуть доступнішими для всіх користувачів.
