Урок 3: Форми (частина 1)

Основні типи полів введення та структура форм

Основи HTML форм

Форми - це основний спосіб збору даних від користувачів на веб-сторінках. HTML5 додав багато нових типів полів введення, які покращують користувацький досвід та автоматично валідують дані.

Базова структура форми

<form action="/submit" method="POST">
    <!-- Поля форми -->
    <button type="submit">Надіслати</button>
</form>

Атрибути форми

  • action - URL, куди надсилаються дані
  • method - метод HTTP (GET або POST)
  • enctype - тип кодування даних (для файлів: multipart/form-data)
  • novalidate - вимикає стандартну валідацію браузера

Label та зв'язок з полями

Тег <label> створює підпис для поля введення і покращує доступність. Клік на label автоматично фокусує відповідне поле. 

<!-- Спосіб 1: вкладення -->
<label>
    Ім'я:
    <input type="text" name="username">
</label>

<!-- Спосіб 2: атрибут for (рекомендований) -->
<label for="email">Email:</label>
<input type="email" id="email" name="email">

Типи полів введення

Текстові поля

<!-- Звичайний текст -->
<label for="name">Ім'я:</label>
<input type="text" id="name" name="name" 
       placeholder="Введіть ваше ім'я">

<!-- Пароль -->
<label for="password">Пароль:</label>
<input type="password" id="password" name="password">

<!-- Email -->
<label for="email">Email:</label>
<input type="email" id="email" name="email" 
       placeholder="user@example.com">

<!-- Телефон -->
<label for="phone">Телефон:</label>
<input type="tel" id="phone" name="phone" 
       placeholder="+380 XX XXX XXXX">

<!-- URL -->
<label for="website">Веб-сайт:</label>
<input type="url" id="website" name="website" 
       placeholder="https://example.com">

Числові поля

<!-- Число -->
<label for="age">Вік:</label>
<input type="number" id="age" name="age" 
       min="18" max="100" step="1" value="25">

<!-- Діапазон (слайдер) -->
<label for="volume">Гучність:</label>
<input type="range" id="volume" name="volume" 
       min="0" max="100" value="50" step="5">
<output for="volume">50</output>

Дати та час

<!-- Дата -->
<label for="birthdate">Дата народження:</label>
<input type="date" id="birthdate" name="birthdate" 
       min="1900-01-01" max="2024-12-31">

<!-- Час -->
<label for="meeting-time">Час зустрічі:</label>
<input type="time" id="meeting-time" name="meeting-time">

<!-- Дата та час -->
<label for="appointment">Дата та час:</label>
<input type="datetime-local" id="appointment" 
       name="appointment">

<!-- Місяць -->
<label for="month">Оберіть місяць:</label>
<input type="month" id="month" name="month">

<!-- Тиждень -->
<label for="week">Оберіть тиждень:</label>
<input type="week" id="week" name="week">

Вибір кольору

<label for="color">Улюблений колір:</label>
<input type="color" id="color" name="color" 
       value="#3498db">

Групування полів: Fieldset та Legend

Елементи <fieldset> та <legend> використовуються для логічного групування пов'язаних полів форми. 

<form>
    <fieldset>
        <legend>Особисті дані</legend>
        
        <label for="firstname">Ім'я:</label>
        <input type="text" id="firstname" name="firstname">
        
        <label for="lastname">Прізвище:</label>
        <input type="text" id="lastname" name="lastname">
        
        <label for="birthday">Дата народження:</label>
        <input type="date" id="birthday" name="birthday">
    </fieldset>
    
    <fieldset>
        <legend>Контактна інформація</legend>
        
        <label for="email">Email:</label>
        <input type="email" id="email" name="email">
        
        <label for="phone">Телефон:</label>
        <input type="tel" id="phone" name="phone">
    </fieldset>
    
    <button type="submit">Зберегти</button>
</form>

Вимикання fieldset

Додавши атрибут disabled до fieldset, ви вимкнете всі поля всередині нього: 

<fieldset disabled>
    <legend>Недоступна секція</legend>
    <!-- Всі поля будуть вимкнені -->
</fieldset>

Чекбокси та радіо-кнопки

Чекбокси (множинний вибір)

<fieldset>
    <legend>Оберіть улюблені мови програмування:</legend>
    
    <label>
        <input type="checkbox" name="languages" value="javascript">
        JavaScript
    </label>
    
    <label>
        <input type="checkbox" name="languages" value="python" checked>
        Python
    </label>
    
    <label>
        <input type="checkbox" name="languages" value="java">
        Java
    </label>
</fieldset>

Радіо-кнопки (одиночний вибір)

<fieldset>
    <legend>Оберіть рівень досвіду:</legend>
    
    <label>
        <input type="radio" name="experience" value="beginner">
        Початківець
    </label>
    
    <label>
        <input type="radio" name="experience" value="intermediate" checked>
        Середній
    </label>
    
    <label>
        <input type="radio" name="experience" value="advanced">
        Просунутий
    </label>
</fieldset>

    <fieldset>

        <div>

            <input type="text" id="reg-username" name="username" 
                   placeholder="Мінімум 3 символи">
        </div>
        
        <div>
            <label for="reg-email">Email:</label>
            <input type="email" id="reg-email" name="email" 
                   placeholder="user@example.com">
        </div>
        
        <div>
            <label for="reg-password">Пароль:</label>
            <input type="password" id="reg-password" name="password">
        </div>
        
        <div>
            <label for="reg-age">Вік:</label>
            <input type="number" id="reg-age" name="age" 
                   min="13" max="120">
        </div>
        
        <div>
            <label for="reg-birthdate">Дата народження:</label>
            <input type="date" id="reg-birthdate" name="birthdate">
        </div>
        
        <div>
            <label for="reg-color">Тема оформлення:</label>
            <input type="color" id="reg-color" name="theme-color" 
                   value="#3498db">
        </div>
        
        <fieldset>
            <legend>Стать</legend>
            <label>
                <input type="radio" name="gender" value="male">
                Чоловік
            </label>
            <label>
                <input type="radio" name="gender" value="female">
                Жінка
            </label>
            <label>
                <input type="radio" name="gender" value="other">
                Інше
            </label>
        </fieldset>
        
        <div>
            <label>
                <input type="checkbox" name="newsletter" value="yes">
                Підписатися на розсилку
            </label>
        </div>
        
        <div>
            <label>
                <input type="checkbox" name="terms" value="accepted" required>
                Я приймаю умови використання
            </label>
        </div>
        
        <button type="submit">Зареєструватися</button>
        <button type="reset">Очистити форму</button>
    </fieldset>
</form>

Атрибути полів введення

Атрибут Опис
placeholder Підказка всередині поля
value Початкове значення
readonly Тільки для читання
disabled Вимкнене поле
autofocus Автоматичний фокус при завантаженні
autocomplete Вмикає/вимикає автозаповнення
name Ім'я поля (для відправки даних)
id Унікальний ідентифікатор

Підсумок

HTML5 надає великий вибір типів полів для створення інтерактивних форм. Використання правильних типів полів покращує користувацький досвід, надає вбудовану валідацію та оптимізує відображення на мобільних пристроях. Завжди використовуйте <label> для кращої доступності та групуйте пов'язані поля за допомогою <fieldset>.
